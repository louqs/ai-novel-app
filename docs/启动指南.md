## 3. 配置 API Key

生成正文需要调用大模型 API。任选一个你有的 Key：

### 方式 A：创建 `.env` 文件（推荐）

在项目根目录创建 `.env` 文件，内容如下（任选一行）：

```bash
# 阿里云百炼（通义千问）— 推荐，国产性价比高
QWEN_API_KEY=sk-你的key

# DeepSeek — 最便宜
DEEPSEEK_API_KEY=sk-你的key

# 智谱 GLM
ZHIPU_API_KEY=你的key

# Kimi（月之暗面）
KIMI_API_KEY=sk-你的key

# Anthropic Claude
ANTHROPIC_API_KEY=sk-ant-你的key

# OpenAI / 任意兼容 API
OPENAI_API_KEY=sk-你的key
```

### 方式 B：系统环境变量

```bash
# Windows PowerShell
$env:QWEN_API_KEY="sk-你的key"

# Windows CMD
set QWEN_API_KEY=sk-你的key

# macOS/Linux
export QWEN_API_KEY=sk-你的key
```

## 4. 启动方式

### 4.1 Web 控制台（推荐）

```bash
# 默认端口 8000
python -m web.backend.main

# 自定义端口
python -m web.backend.main --port 9000

# 或使用 uvicorn
uvicorn web.backend.main:app --host 127.0.0.1 --port 8000 --reload
```

`--reload` 参数使代码修改后自动重启（开发时用）。

### 4.2 CLI 命令行

```bash
# 交互式创建项目
python -m cli.main init

# 查看帮助
python -m cli.main --help

# 查看某个命令的详细帮助
python -m cli.main generate --help
```

### 4.3 Docker

```bash
# 构建镜像
docker build -t ai-novel-app .

# 启动
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止
docker-compose down
```

## 6. CLI 命令行

`python -m cli.main <命令>` 或安装后用 `novel <命令>`。

### 6.1 项目管理

```bash
# 交互式创建项目
python -m cli.main init

# 查看项目状态
python -m cli.main status

# 构建世界观和人物
python -m cli.main world -p proj_xxx

# 生成大纲（30章，2卷）
python -m cli.main outline -p proj_xxx --chapters 30 --volumes 2
```

### 6.2 章节生成

```bash
# 生成第1章（普通模式）
python -m cli.main generate -c 1 -p proj_xxx

# 流式生成（逐字输出，像打字机）
python -m cli.main generate -c 1 --stream
```

### 6.3 反AI检测

```bash
# 检测文本
python -m cli.main check "他不禁微微抬起头，仿佛看到了前所未有的景象"

# 检测文件
python -m cli.main check -f novel_output/proj_xxx/chapters/ch_0001.md
```

### 6.4 导出

```bash
# 导出 TXT（网文平台通用格式）
python -m cli.main export -p proj_xxx

# 导出 EPUB（电子书）
python -m cli.main export -p proj_xxx --format epub

# 导出 Markdown
python -m cli.main export -p proj_xxx --format md
```

### 6.5 其他命令

```bash
# 数据看板
python -m cli.main stats -p proj_xxx

# AI 写作教练（整本分析）
python -m cli.main coach -p proj_xxx

# 分析单章
python -m cli.main coach -p proj_xxx --chapter 5

# 知识图谱
python -m cli.main graph export          # 导出全图
python -m cli.main graph characters      # 人物关系统计

# 知识包
python -m cli.main pack list             # 已安装的包
python -m cli.main pack catalog          # 内置目录
python -m cli.main pack install -n anti-ai-patterns

# 模型管理
python -m cli.main models list           # 列出 Provider
python -m cli.main models switch --provider qwen --model qwen-max --tier premium

# 封面生成
python -m cli.main cover -p proj_xxx

# 启动 Web 服务
python -m cli.main serve
```

## 7. 完整创作流程

### Web 界面流程

```
第1步: 打开 http://127.0.0.1:8000
       → 填写书名、选平台 → 创建项目

第2步: 打开 http://127.0.0.1:8000/workbench?project_id=你的项目ID
       → 左侧大纲区点击「生成」→ AI 自动规划大纲

第3步: 点击大纲中的第1章 → 点击「✨生成」→ AI 撰写正文
       或点击「⚡流式」→ 逐字输出

第4步: 章节写完后 → 点击「🔍检测」→ 查看 AI 评分
       → 如评分低可手动修改或用流式重写

第5步: 继续生成第2章、第3章...

第6步: 导出 → http://127.0.0.1:8000 项目卡片中操作
```

### CLI 流程

```bash
# 1. 创建项目
python -m cli.main init
# → 输入书名、选平台 → 得到项目ID

# 2. 构建世界观
python -m cli.main world -p proj_xxx

# 3. 生成大纲
python -m cli.main outline -p proj_xxx --chapters 100

# 4. 生成第1章
python -m cli.main generate -c 1 -p proj_xxx --stream

# 5. AI检测
python -m cli.main check -f novel_output/proj_xxx/chapters/ch_0001.md

# 6. 导出
python -m cli.main export -p proj_xxx --format epub
```

## 8. 切换大模型

### Web 界面

```
http://127.0.0.1:8000/models
→ 看到所有 Provider 列表
→ 选择 Tier + Provider + Model → 点击「应用切换」
→ 即刻生效，无需重启
```

### CLI

```bash
# 列出可用模型
python -m cli.main models list

# 切换 premium tier 到通义千问
python -m cli.main models switch --provider qwen --model qwen-max --tier premium

# 测试连接
python -m cli.main models test --provider qwen
```

### 添加新 Provider

编辑 `config/default.yaml`，在 `providers:` 下添加：

```yaml
  - name: my-provider
    type: openai_compatible
    base_url: https://api.example.com/v1
    api_key_env: MY_API_KEY
    default_model: my-model
    models:
      - my-model
```

然后重启服务即可在列表中选择。

## 9. 常见问题

### Q: 启动后浏览器显示 "Internal Server Error"

端口可能被占用，换一个端口：
```bash
python -m web.backend.main --port 9000
```

### Q: 生成章节时报错 "所有 LLM Provider 均不可用"

1. 检查 API Key 是否正确设置
2. 检查网络是否能访问 API 地址
3. 运行连接测试：`python -m cli.main models test`

### Q: 生成的内容有 AI 味

1. 使用反AI检测工具检查：http://127.0.0.1:8000/anti-ai
2. 在写作教练中分析章节问题
3. 手动修改检测到的问题词汇
4. 用流式模式（`--stream`）重新生成

### Q: 如何提高生成质量

1. **完善世界观和人物设定**：在生成阶段花时间做好设定
2. **写好大纲**：每章有明确的概要和大纲节点
3. **使用自动修订**：`generate` 命令会自带质量修订
4. **切换更强的模型**：如用 qwen-max 或 deepseek-chat

### Q: 依赖安装失败

```bash
# 如果 pip install 报错，尝试升级 pip
python -m pip install --upgrade pip

# 逐个安装可能出问题的包
pip install anthropic chromadb neo4j rank-bm25

# Windows 上某些包可能需要 Visual C++ Build Tools
# 下载: https://visualstudio.microsoft.com/visual-cpp-build-tools/
```

### Q: 如何卸载/重置

```bash
# 删除虚拟环境
rm -rf .venv

# 清理数据
rm -rf novel_output data

# 重新安装
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Q: 运行测试

```bash
# 快速测试（无需 API）
pytest tests/ -q --ignore=tests/test_e2e.py

# 冒烟测试
pytest tests/test_e2e.py -m smoke -v

# 完整 E2E（需 API Key）
QWEN_API_KEY=sk-xxx pytest tests/test_e2e.py -m e2e -v -s
```
