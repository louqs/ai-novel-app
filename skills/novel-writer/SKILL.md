# 中篇小说创作 Skill

> 融合长篇框架精华，针对中篇小说特性优化

## 一、核心定位

**中篇 vs 短篇 vs 长篇**：
- 短篇（1-10万字）：三幕结构，精简人物
- **中篇（10-50万字）**：五幕结构，分卷管理，伏笔系统
- 长篇（50万+）：六幕结构，复杂群像，多线并行

**中篇黄金法则**：
1. **分卷清晰** — 每卷有完整的故事弧
2. **伏笔贯穿** — 伏笔在多卷中铺设和回收
3. **人物成长** — 主角有明确的成长弧光
4. **节奏平衡** — 快慢交替，张弛有度

---

## 二、五幕结构（中篇专用）

### 第一幕：开局（前10%）
- **目的**：建立世界观、主角、核心冲突
- **章节**：1-5章
- **要点**：
  - 主角是谁？什么处境？
  - 世界观核心规则
  - 核心冲突是什么？
  - 金手指/特殊能力

### 第二幕：发展（10-30%）
- **目的**：主角初步尝试解决冲突，小成功+小挫折
- **章节**：6-15章
- **要点**：
  - 逐步展开世界观
  - 引入盟友和对手
  - 建立人物关系
  - 第一个小高潮

### 第三幕：转折（30-60%）
- **目的**：冲突升级，主角面临更大挑战
- **章节**：16-30章
- **要点**：
  - 反派露出真面目
  - 主角遭遇重大挫折
  - 人物关系变化
  - 中期高潮

### 第四幕：高潮（60-85%）
- **目的**：主角主动反击，解决核心冲突
- **章节**：31-42章
- **要点**：
  - 主角觉醒/成长
  - 集结盟友
  - 最终对决铺垫
  - 高潮爆发

### 第五幕：结局（85-100%）
- **目的**：解决冲突，收束故事
- **章节**：43-50章
- **要点**：
  - 最终对决
  - 冲突解决
  - 人物弧光完成
  - 余韵收束

## 三、分卷管理

### 卷级结构
```
中篇小说（30万字）
├── 第一卷：觉醒篇（10万字，10章）
├── 第二卷：成长篇（10万字，10章）
└── 第三卷：决战篇（10万字，10章）
```

### 每卷设计
- **卷级目标**：每卷解决一个阶段性问题
- **卷级高潮**：每卷结尾有高潮
- **卷级转折**：每卷开头有新冲突
- **人物弧光**：每卷有人物成长

### 卷间衔接
- **伏笔传递**：上卷伏笔在下卷回收
- **人物延续**：核心人物贯穿全书
- **世界观扩展**：逐步展开世界观

## 四、伏笔系统（中篇精简版）

### 伏笔生命周期
```
铺设 → 推进 → 回收
```

### 伏笔管理模板
```markdown
| 伏笔ID | 描述 | 铺设章节 | 推进章节 | 回收章节 | 状态 |
|--------|------|----------|----------|----------|------|
| F001 | 主角身世之谜 | 第1章 | 第10章 | 第25章 | 已回收 |
| F002 | 神秘组织 | 第5章 | 第15章 | 第40章 | 进行中 |
```

### 伏笔原则
- **每卷至少3个伏笔** — 保持悬念
- **每5章推进一次** — 保持读者期待
- **回收要有满足感** — 不能虎头蛇尾

## 五、人物关系网

### 核心人物（3-5人）
```markdown
主角
├── 盟友1（功能：协助 + 衬托）
```

## 七、节奏控制（中篇版）

### 卷级节奏
```
第1卷：开局 → 小高潮 → 铺垫
第2卷：冲突 → 中高潮 → 转折
第3卷：高潮 → 最终对决 → 收束
```

### 章级节奏
- **每3章一个小高潮**
- **每卷一个大高潮**
- **快慢交替**：紧张→缓和→紧张

### 钩子设计
- **章头钩子**：前300字有冲突或悬念
- **章尾钩子**：每章结尾留钩子
- **卷尾钩子**：每卷结尾有大悬念

## 八、写作铁律（中篇版）

### 必做
1. **分卷清晰** — 每卷有完整故事弧
2. **伏笔贯穿** — 伏笔在多卷中铺设回收
3. **人物成长** — 主角有明确成长弧光
4. **世界观完整** — 规则自洽，不矛盾
5. **节奏平衡** — 快慢交替，张弛有度

### 禁止
1. **前后矛盾** — 世界观/人物/时间线不能矛盾
2. **伏笔丢失** — 铺设的伏笔必须回收
3. **人物崩坏** — 角色行为必须符合设定
4. **节奏失控** — 不能一直快或一直慢
5. **水字数** — 每章都要有明确目的

## 十、快速创作流程

```
1. 确定题材和核心卖点（1-2天）
   ↓
2. 设计世界观和人物（2-3天）
   ↓
3. 写五幕大纲和分卷规划（2-3天）
   ↓
4. 写初稿（每章2-3小时）
   ↓
5. 润色和降重（每章1小时）
   ↓
6. 自检和修改（每卷完成后）
```

## 十一、与项目集成

### 使用方式
1. 创建新项目时选择"中篇小说"类型
2. 系统自动应用五幕结构模板
3. 写作时自动检查中篇规则
4. 生成时自动优化节奏

### 配置选项
```yaml
novel_story:
  enabled: true
  target_words: 300000        # 目标总字数
  target_chapters: 50         # 目标章节数
  volumes: 3                  # 分卷数
  structure: "five_act"       # 五幕结构
  foreshadow_tracking: true   # 伏笔追踪
  auto_check: true            # 自动检查规则
```
