# 短篇小说创作 Skill

> 基于长篇框架提炼，针对短篇小说特性优化

## 一、核心定位

**短篇 vs 长篇的本质区别**：
- 长篇：慢火炖高汤，逐步展开世界观和人物
- 短篇：精准手术刀，每一章都要有明确目的

**短篇黄金法则**：
1. **开头即冲突** — 前500字必须抓住读者
2. **人物即故事** — 3-5个核心人物足够
3. **单一主线** — 一条主线贯穿始终
4. **结尾即高潮** — 最后一章要有满足感

---

## 二、三幕结构（短篇专用）

### 第一幕：开局（前20%）
- **目的**：建立主角、抛出核心冲突、展示金手指
- **时间线**：1-3章
- **要点**：
  - 主角是谁？什么处境？
  - 核心冲突是什么？
  - 金手指/特殊能力是什么？

### 第二幕：发展（中间60%）
- **目的**：主角尝试解决冲突，遭遇挫折和成长
- **时间线**：4-8章
- **要点**：
  - 每章都有小目标和小冲突
  - 逐步升级困难
  - 穿插支线和人物关系

### 第三幕：高潮+结局（最后20%）
- **目的**：最终对决、解决冲突、情感收束
- **时间线**：9-10章
- **要点**：
  - 高潮要足够强烈
  - 结局要有满足感
  - 可以留一点余韵

---

## 三、代入感塑造（短篇精华版）

### 1. 快速标签化
- **原则**：前200字让读者记住主角
- **方法**：核心标签 + 反差细节 = 活人
- **示例**：穷小子 + 隐藏的天才能力

### 2. 五感代入
- **视觉**：具体的颜色、形状、光影
- **听觉**：环境音、对话语气
- **嗅觉**：食物、环境、季节
- **触觉**：温度、质感、疼痛
- **味觉**：食物、苦涩、甜蜜

### 3. 情绪共鸣
- **核心公式**：困境 → 挣扎 → 希望 → 得偿所愿
- **技巧**：让读者看到主角的努力和付出

---

## 四、人物构建（短篇精简版）

### 主角设定模板
```markdown
- 姓名：
- 年龄：
- 外貌（3个关键特征）：
- 性格标签（2-3个）：
- 核心欲望：
- 致命弱点：
- 金手指：
```

### 配角原则
- **数量**：2-4个核心配角
- **功能**：每个配角必须推动主线或展现主角某一面
- **标签**：每人一个鲜明标签（如"话痨"、"冷面"、"吃货"）

### 反派设计
- **动机**：反派的行为必须有合理动机
- **威胁**：反派必须让读者感到真实威胁
- **结局**：反派的结局要有说服力

---

## 五、节奏控制

### 短篇节奏公式
```
第1章：抛冲突 + 展金手指
第2-3章：小目标 + 小挫折 + 小成功
第4-6章：升级困难 + 人物关系深化
第7-8章：危机爆发 + 低谷
第9章：最终对决 + 高潮
第10章：收束 + 余韵
```

### 钩子设计
- **章头钩子**：前300字必须有冲突或悬念
- **章尾钩子**：每章结尾留钩子（悬念/危机/反转）
- **节奏变化**：紧张→缓和→紧张，不要一直紧绷

---

## 六、写作铁律

### 必做
1. **展示不讲述** — 用动作和细节，不要直接说"他很愤怒"
2. **对话独立成段** — 每句对话单独一段
3. **口语化表达** — 用"俺/咱/啥/咋"等口语
4. **五感描写** — 每个场景至少2种感官
5. **章尾钩子** — 每章结尾留悬念

### 禁止
1. **AI模板词** — "笑了笑/点了点头/深吸一口气"
2. **心理标签** — "他感到愤怒/悲伤/开心"
3. **流水账** — 没有冲突的平铺直叙
4. **词藻堆砌** — 不要故意秀文笔
5. **人设崩坏** — 角色行为必须符合设定

## 七、创作自检清单

### 开篇检查
- [ ] 前500字有冲突或悬念？
- [ ] 主角标签清晰？
- [ ] 金手指已展示？
- [ ] 读者能快速代入？

### 过程检查
- [ ] 每章有明确目标？
- [ ] 每章有钩子？
- [ ] 人物行为符合设定？
- [ ] 节奏有变化？

### 结局检查
- [ ] 冲突已解决？
- [ ] 人物弧光完成？
- [ ] 有满足感？
- [ ] 有余韵？

---

## 八、快速创作流程

```
1. 确定题材和核心卖点（30分钟）
   ↓
2. 设计主角和反派（30分钟）
   ↓
3. 写三幕大纲（1小时）
   ↓
4. 写初稿（每章1-2小时）
   ↓
5. 润色和降重（每章30分钟）
   ↓
6. 自检和修改（1小时）
```

---

## 九、与项目集成

### 使用方式
1. 创建新项目时选择"短篇小说"类型
2. 系统自动应用三幕结构模板
3. 写作时自动检查短篇规则
4. 生成时自动优化节奏

### 配置选项
```yaml
short_story:
  enabled: true
  target_chapters: 10        # 目标章节数
  target_words_per_chapter: 3000  # 每章目标字数
  structure: "three_act"     # 三幕结构
  auto_check: true           # 自动检查短篇规则
```
