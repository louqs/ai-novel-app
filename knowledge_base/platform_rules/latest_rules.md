# 主流网文平台最新规则与算法变化（截至2026年6月）

> **信息时效性说明**：以下内容基于2026年5月至6月各平台官方公告、作者后台更新日志及行业监测数据整理，适用于当前（2026年6月）运营环境。

## 番茄小说

### 全勤规则（2026年6月版）
- **基础全勤**：日更≥4000字，当月有效更新天数≥28天，可获1500元基础全勤奖。
- **阶梯全勤**：
  - 日均5000字以上且完读率≥35%，额外奖励500元；
  - 日均6000字以上且章节互动率（点赞+评论/阅读量）≥2%，再奖500元。
- **新书保护期**：首月仅需日更3000字、更新≥20天即可参与全勤，但不计入阶梯奖励。
- **违规扣减**：AI生成内容占比超15%（经平台检测），取消当月全勤资格。

### 推荐算法变化
- **核心指标调整**：从“点击率+完读率”双核模型，升级为“**留存率×互动深度×用户停留时长**”三维加权模型。
- **冷启动优化**：新书前3章若72小时内留存率＞45%，将获得“快速通道”标签，进入更高流量池。
- **AI辅助分发**：引入大模型预测用户兴趣迁移路径，对跨品类作品（如“科幻+言情”）进行动态标签融合推荐。
- **反刷机制加强**：异常阅读行为（如短时高频翻页、无互动阅读）将被降权，严重者限流7–30天。

### 热门品类（2026年Q2数据）
1. **高概念都市**（含赛博朋克职场、AI伦理家庭剧）
2. **轻科幻种田**（星际基建+慢生活）
3. **悬疑情感**（女性向心理悬疑，强调情绪张力）
4. **新国风奇幻**（结合非遗、民俗、山海经元素的东方幻想）
5. **反套路快穿**（主角具备系统对抗意识，打破任务逻辑）

## 起点中文网

### 订阅分成变化
- **标准分成比例**：维持作者70% / 平台30%，但新增“**优质内容激励池**”：
  - 月订阅收入≥5万元的作品，超出部分作者分成提升至75%；
  - 连续3个月进入畅销榜TOP100，可申请“白金保底+分成”混合合约。
- **免费章节策略调整**：VIP章节前可设最多30章免费（原为20章），但第21–30章需满足“章节均订≥1万”方可解锁。
- **打赏分成**：盟主及以上打赏，作者分成比例由80%提升至85%。

### 推荐机制
- **“三端协同”推荐体系**：PC站、APP、微信小程序数据打通，用户跨端行为纳入推荐权重。
- **书荒救济计划**：连续7天日活下降超20%的老书，若作者提交“剧情重启方案”并通过审核，可获得一次重新进入新书推荐位的机会。
- **AI大纲评估前置**：签约阶段需提交完整故事大纲，由AI评估“剧情密度”“角色弧光完整性”，评分低于60分不予签约或限制推荐资源。
- **社区互动加成**：在“本章说”中作者回复读者≥50条/周，且互动质量达标（非复制粘贴），下周推荐曝光量提升10–15%。

## 晋江文学城

### 榜单规则
- **VIP金榜**：仅统计付费章节订阅数据，剔除包月用户阅读量，防止“刷榜”。
- **佳作榜**（原“新晋榜”）：
  - 入榜条件：开V后7日内千字订阅≥80；
  - 排名依据：综合“首订增速”“追订率”“读者收藏转化率”；
  - 每日更新，前20名获得首页banner轮播。
- **衍生热度榜**：新增“IP衍生潜力指数”，结合站外微博、LOFTER、抖音话题声量，影响编辑重点推书决策。

### 签约政策变化
- **分级签约制度**（2026年4月起实施）：
  - **S级**：保底+高分成（作者60%），要求开篇3万字内有明确CP线及高情感浓度；
  - **A级**：纯分成（作者50%），需完成10万字且通过剧情连贯性AI检测；
  - **B级**：试签约，仅开放基础推荐位，3个月内未达均订500自动解约。
- **AI内容限制**：禁止使用AI生成正文，允许用于灵感辅助或大纲梳理；一经查实AI代写，永久封禁作者账号并追回稿酬。
- **题材备案制**：涉及现实敏感题材（如医疗、司法、校园暴力）需提前提交创作说明，审核通过后方可上架。
