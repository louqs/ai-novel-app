# 女频爱情 — 体裁靶值（G 层参数）

> **用途**：[[规则分类抽样框]] §C 体裁靶值的体裁包实现。通用写作技能中「换体裁该值就该变」的
> 量化阈值到这里取值。调用约定：通用规则写「向本体裁靶值靠拢；未给定则回退通用默认」。
> **数值来源**：沿用本体裁 `题材正文创作补充规则.md` 既有口径，只做显式化，不凭空造数。

## 一、靶值表（润色 / 审阅共用）

| 参数 key | 女频爱情靶值 | 通用默认（回退值） | 依据 |
|---|---|---|---|
| `字数窗口` | 起点原始章节需求（向主平台取值） | 2500–5000 CJK | 「正文字数符合起点原始章节需求」 |
| `章首抓力窗口` | 前 **1000** 字同时交付情感抓手 + 现实软压力 | 前 300 字 | 「开篇前1000字同时交付职业硬抓手与现实软压力」 |
| `对话比例` | **40%–60%**（偏高） | 25%–55% | 情感推进高度依赖对白、潜台词与试探 |
| `情绪外化强制度` | 高 — 情绪默认走身体反应/手上动作/物件触感 | 中（§D倾向） | 「不直接写他很怕/她很痛苦」 |
| `中爽点间隔` | 情感进程每前进一步即需一次"追赶事件"兑现 | 无 | 「升级式恋爱节奏：情感进程→追赶事件」 |
| `主视角分配` | 女主视角 ≥80% | ≥80% | 女频默认女主限知视角 |

## 二、体裁专属红线增量（叠加通用 §A）

1. **关系权力不得失衡** — 男性角色「强而不压、偏爱但尊重边界」；禁止控制型关系与失衡权力结构。
2. **杀死主线的触发物** — 若用"杀死主线"桥段，触发物必须是全书最核心外部冲突，非误会型。
3. **章引语不剧透** — 禁止在章引语直接讲核心思想、暗线结论、下一章剧情、设定参数、作者编号。

---

## 三、体裁专属诊断信号增量（叠加通用 §D）

- **情感进程 vs 实际关系的差距监控**：两者差距过大且久未追赶时，**倾向**加快追赶节奏，避免读者积累不满。
- **专业/信息差爽点优先**：**优先**让主角因懂流程/点位/话术早一步看出不对，而非堆术语。
- **黄金三章闭环**：**建议**前三章完成核心危机前置 + 关系张力建立 + 首个情绪回报落地。
