# 玄幻 — 体裁靶值（G 层参数）

> **用途**：[[规则分类抽样框]] §C 体裁靶值的体裁包实现。调用约定：通用规则写「向本体裁靶值靠拢；
> 未给定则回退通用默认」。**数值来源**：基于玄幻类型公认常识（修炼升级 + 世界观铺陈 + 爽点节奏）。
> 标注 ⚙ 的项为类型常识基线，建议实际项目按竞品数据进一步校准。

---

## 一、靶值表（润色 / 审阅共用）

| 参数 key | 玄幻靶值 | 通用默认（回退值） | 依据 |
|---|---|---|---|
| `字数窗口` | 起点原始章节需求（向主平台取值） | 2500–5000 CJK | 起点平台惯例 |
| `章首抓力窗口` | 前 300 字立冲突/压制/异象 | 前 300 字 | 通用默认 + 玄幻开篇惯例 |
| `对话比例` | ⚙ **30%–50%**（修炼/打斗/世界观叙述占比偏高） | 25%–55% | 战斗与设定描写多，对话占比偏低 |
| `单处解释长度上限` | ⚙ 200 字（功法/境界/世界观设定容忍偏高，须可视化） | 150 字 | 力量体系需说明，但忌说明书式堆砌 |
| `中爽点间隔` | ⚙ 每 3–5 章一次阶段性爽点（突破/打脸/夺宝/扬名） | 无 | 玄幻升级流爽点节奏惯例 |
| `零画面段落上限` | ⚙ 350 字（功法/秘境抽象设定容忍略高） | 300 字 | 设定密集段门槛略松仍设上限 |
| `主视角分配` | 单一主视角 ≥80% | ≥80% | 通用默认 |

## 二、体裁专属红线增量（叠加通用 §A）

1. **力量体系自洽** — 境界、功法、战力的边界与代价须前后一致，不得为打赢临时加设定。
2. **升级有代价/有阻力** — 突破、夺宝、变强须伴随资源、风险、敌意或瓶颈，禁止零阻力顺风躺赢。
3. **设定具象化** — 世界观/功法须通过情节、战斗、交易具象化，不接受长篇说明书式铺陈。

---

## 三、体裁专属诊断信号增量（叠加通用 §D）

- **金手指克制**：主角优势**倾向**绑定代价、隐患或使用门槛，避免无脑无敌导致追读疲劳。
- **爽点轮换**：**倾向**让突破/打脸/夺宝/扬名等爽点类型轮换，连续同类不超过 3 章。
- **境界感可感**：实力差距**优先**用可见后果（压制感、环境反应、旁观者反应）呈现，而非数值口播。
