# 新增体裁知识包 · 生成规范（AI 执行用）

> **本文件是给 AI 的操作规范**。当用户要求「新增 XX 体裁」时，AI 应只读本文件即可产出
> 符合系统约定、能被生成/优化/大纲管线自动吸收的体裁包。**全程不改任何代码**。
>
> 适用系统：本仓库的 AI 小说生成系统。接入层为 `core/knowledge_resolver.py`（约定式自动发现）。

---

## 0. 核心原则（先理解再动手）

- **约定优于配置**：系统按固定目录与文件名约定自动发现体裁知识，无需注册、无需改代码。
- **目录名直配**：体裁标签 = 目录名即命中。新建 `genre_skills/{体裁}/` 目录即被识别。
- **只填差量**：靶值表只写「与通用默认不同」的项；未列项自动回退通用默认，不要全部照抄。
- **静默回退**：任何文件缺失都不会报错，系统走通用默认。所以宁缺毋滥、宁空毋错。
- **诚实标注**：拿不准的量化值（对话比例、爽点间隔等）必须标 `⚙` 并注明「类型常识基线，建议按竞品校准」，不得伪装成精确数据。

## 2. 靶值槽模板（必做 · 严格按格式）

> ⚠️ **格式硬约束**（解析器 `_parse_target_table` 依赖）：
> §一靶值表必须是 4 列 markdown 表 `| 参数 key | 体裁靶值 | 通用默认 | 依据 |`。
> 解析器取**第1列为 key、第2列为靶值**。参数 key 必须与下方「标准 key 名」完全一致，否则取不到值。
> 区间型靶值（对话比例、字数等）写成 `30%–50%` / `2500–4500 CJK`，解析器按前两个数字取区间。

**标准 key 名**（务必用这些，不要自创同义词）：
`字数窗口`、`章首抓力窗口`、`对话比例`、`单处解释长度上限`、`中爽点间隔`、`零画面段落上限`、`主视角分配`。

复制下方模板，按体裁改值，**删掉与通用默认相同的行**：

```markdown
# {体裁名} — 体裁靶值（G 层参数）

> **用途**：规则分层 §C 体裁靶值的体裁包实现。调用约定：通用规则写「向本体裁靶值靠拢；
> 未给定则回退通用默认」。**数值来源**：基于 {体裁} 类型公认常识 /（若有）竞品数据。
> 标注 ⚙ 的项为类型常识基线，建议实际项目按竞品数据进一步校准。

---
```

## 4. 阶段提示槽模板（推荐 · 务必用自包含写法）

> ⚠️ **关键防坑**：**不要照抄 `AI科幻/.github/prompts/创建小说正文.prompt.md`**！
> 那是「路由版」，会引用 `AI科幻-创建小说正文` 等专项 Skill；新体裁通常没有这些 Skill，
> 引用就指向不存在的文件。**新体裁一律用下方「自包含版」**（参照 `玄幻/` 的同名文件）。
>
> 系统读取此文件时会跳过 YAML 头、取正文前 2000 字注入正文生成。所以正文部分要写成
> **直接可用的题材写作要点**，不是路由说明。

路径 `{体裁名}/.github/prompts/创建小说正文.prompt.md`：

```markdown
---
name: 创建小说正文
description: {体裁}题材章节正文。强调（本体裁的2-3个核心追读点）。关键词：章节正文、{体裁}。
argument-hint: '例如：按分卷大纲创作第27章 / 重写第1卷第9章正文'
agent: 小说作者
---

# 创建小说正文（{体裁}）

> 本 Prompt 为自包含 {体裁} 正文创作要点。正文施工共性骨架请读取
> `writing_skills/通用-创建小说正文`，量化阈值向 `genre_skills/{体裁}/靶值.md` 取值。

## {体裁}正文施工要点（题材专项，叠加通用流程）

### 一、（本体裁红线，与靶值§二呼应）
- （要点）

### 二、爽点 / 情绪驱动（向靶值取节奏）
- （爽点类型轮换、间隔，向靶值靠拢）

### 三、（本体裁特有的"可视化/具象化"要求）
- （要点）

### 四、章节结构（向靶值取窗口）
- 章首：靶值「章首抓力窗口」内立钩子。
- 中段：至少一次实质推进。
- 章末：把角色推向更糟局面或更危险问题。

## 最小执行约束
- 每章必须有明确读者回报与短线目标；中段兑现一次实质推进；章末留下新缺口。
- 设定不得写成教程，必须写成角色正在经历、承受、博弈的事。
```

## 5. 完成后验证（必跑）

建完文件后，跑这条命令确认被系统识别（把「体裁名」换成实际名）：

```bash
python -c "from core import knowledge_resolver as kr; print('目录:', kr.resolve_genre_dirs(['体裁名'])); print('靶值:', kr.genre_targets(['体裁名'])); print('对话区间:', kr.ratio_range('对话比例', ['体裁名'], default=(25.0,100.0)))"
```

**期望输出**：
- `目录:` 返回 `['体裁名']`（非空 = 目录直配成功）
- `靶值:` 返回非空字典，含你填的 key
- `对话区间:` 返回你填的数值对（如 `(30.0, 50.0)`）；若返回 default 说明 key 名写错或格式不对

三项任一为空/异常 → 检查：目录名是否精确、靶值表是否 4 列、参数 key 是否用了标准名。
