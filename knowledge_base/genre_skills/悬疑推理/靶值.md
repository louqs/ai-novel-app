# 悬疑推理 — 体裁靶值（G 层参数）

> **用途**：[[规则分类抽样框]] §C 体裁靶值的体裁包实现。调用约定：通用规则写「向本体裁靶值靠拢；
> 未给定则回退通用默认」。**数值来源**：基于 `题材边界与创作说明.instructions.md` 与类型公认常识。
> 标注 ⚙ 的项为类型常识基线，建议实际项目按竞品数据进一步校准。

---

## 一、靶值表（润色 / 审阅共用）

| 参数 key | 悬疑推理靶值 | 通用默认（回退值） | 依据 |
|---|---|---|---|
| `字数窗口` | 起点原始章节需求（向主平台取值） | 2500–5000 CJK | 起点平台惯例 |
| `章首抓力窗口` | 前 300 字立悬念/谜面/异常 | 前 300 字 | 通用默认 + 推理开篇惯例 |
| `对话比例` | ⚙ **45%–65%**（盘问/推理对白密集） | 25%–55% | 审讯、推理交锋、信息盘问对白占比高 |
| `线索密度` | 每章至少 1 条可回收线索 | 无 | 题材边界「线索密度与回收」 |
| `反转间隔` | ⚙ 每 5–8 章一次显著反转/阶段揭示 | 无 | 类型常识：维持悬念又不疲劳的节奏 |
| `线索回收跨度` | ⚙ 显著线索 ≤ 当前卷内回收 | 无 | 「禁止线索无回收」，避免跨卷遗忘 |
| `主视角分配` | 单一主视角 ≥80%（保推理公平性） | ≥80% | 「推理公平性」要求视角稳定 |

---

## 二、体裁专属红线增量（叠加通用 §A）

1. **推理公平性** — 破案所需关键线索须在揭晓前向读者公平呈现，不藏线作弊。
2. **线索必回收** — 禁止显著线索无回收（埋了不收）。
3. **禁机械降神** — 禁止凭空出现的信息/证人/能力直接解谜。
4. **反转有据** — 反转须由前文线索支撑，不为反转而反转。

---

## 三、体裁专属诊断信号增量（叠加通用 §D）

- **逻辑闭环快感优先**：满足点**优先**落在"原来如此"的逻辑闭环，区别于都市悬疑的细思极恐代入。
- **读者同步推理**：**倾向**让读者拥有与主角同步推理、可预先解谜的信息，而非单方揭晓。
- **线索回收节奏**：**检查**每条显著线索是否在读者尚未遗忘的章节跨度内回收。
