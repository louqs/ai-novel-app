# 异能志怪 — 体裁靶值（G 层参数）

> **用途**：[[规则分类抽样框]] §C 体裁靶值的体裁包实现。调用约定：通用规则写「向本体裁靶值靠拢；
> 未给定则回退通用默认」。**数值来源**：沿用本体裁 `题材定位与硬约束.md` 既有口径，只做显式化。
> 本体裁原文已有明确量化（爽点轮换/中爽点间隔），直接采纳。

## 一、靶值表（润色 / 审阅共用）

| 参数 key | 异能志怪靶值 | 通用默认（回退值） | 依据 |
|---|---|---|---|
| `字数窗口` | 起点原始章节需求（向主平台取值） | 2500–5000 CJK | 起点平台惯例 |
| `章首抓力窗口` | 前 300 字现异常触发 | 前 300 字 | 「开篇三章：异常触发→规则初示→首次对抗与代价」 |
| `单处解释长度上限` | 200 字（硬规则/机制说明容忍偏高） | 150 字 | 「允许硬程序硬规则，但不接受说明书式铺陈」 |
| `中爽点间隔` | 每 **3–5** 章至少一次阶段性中爽点 | 无 | 原文明确量化 |
| `爽点主类型轮换` | 连续 **5** 章内避免主类型完全重复 | 无 | 原文明确量化 |
| `同类镜头连续上限` | 打脸/碾压/反转镜头连续 **≤3** 章 | 无 | 原文明确量化 |
| `主视角分配` | 单一主视角 ≥80% | ≥80% | 通用默认 |

## 二、体裁专属红线增量（叠加通用 §A）

1. **规则可博弈、不开金手指** — 异能/异象的能力边界、触发条件、代价规则须前后一致、可被角色博弈。
2. **抽象必具象化** — 抽象讨论必须通过情境、对话、交易与代价具象化；不接受说明书式世界观铺陈。
3. **主题不说教** — 线索揭示/证据互证推进社会议题时，用人物命运与后果显影，禁止说教。

---

## 三、体裁专属诊断信号增量（叠加通用 §D）

- **智性爽与情绪回报并重**：爽点不等于无脑刺激；「智商在线」「规则可博弈」「反击与代价并存」**同样有效**。
- **爽点可审计**：爽点回报**倾向**绑定证据载体（界面/日志/编号/回执/口供/物证）与代价（关系/职业/名誉/法律/心理）。
- **每章爽点规划**：**建议**每章预先规划「爽点主类型×1 + 辅类型×0–1」，并落地 1–2 个章内微爽点。
- **主题—谜题绑定**：**建议**每章至少 1 次让线索揭示同时推进社会议题。
