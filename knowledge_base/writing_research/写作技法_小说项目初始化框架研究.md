# 小说项目初始化框架研究

> 在选定平台与题材之后、设计大纲之前，需要完成的系统性项目策划工作。

## 研究课题

**课题**：小说项目初始化 Skill 的内容框架设计

**背景**：作者在开始设计大纲之前，已经选定了目标平台（如起点中文网、七猫、番茄、晋江等）和目标题材（如都市悬疑、科幻、职场、爱情等），但接下来还需要做一系列决策和设定工作，才能进入大纲设计阶段。这些决策的质量直接影响作品的吸引力和商业潜力。

**核心问题**：选定平台+题材后，在设计大纲前，还需要设定什么？如何系统化、体系化地完成这项"地基"工作？

**主研究域**：写作技法研究

**辅助研究域**：读者/市场研究、题材趋势研究

## 研究方法与来源

- 网文行业研究资料与深度分析文章（虎嗅、中国作家网、中国社会科学网等）
- 网文写作方法论与教学资料（起点成神指南、系统流分析、爽点设计等）
- 平台生态访谈与行业报告（纵横中文网编辑访谈、2025中国网络文学发展研究报告等）
- 网文写作社区与教程（马良写作、网文666等）
- 现有 Skill 体系梳理（本仓库通用 Skills 总表）

## 核心发现

### 发现一：现有 Skill 体系中没有覆盖"项目初始化"阶段

现有 Skill 体系已经覆盖了：
- ✅ 题材定位框架 → 已有 `通用-设计题材定位框架`
- ✅ 人物传记设计 → 已有 `通用-设计人物传记`
- ✅ 故事设定设计 → 已有 `通用-设计故事设定`
- ✅ 总大纲/分卷大纲设计 → 已有 `通用-设计总大纲`、`通用-设计分卷大纲`
- ✅ 故事面设计 → 已有 `通用-设计故事面`
- ✅ 书名/简介/封面 → 已有 `通用-设计书名`、`通用-撰写内容简介`、`通用-设计封面生图提示词`
- ✅ 平台签约评估 → 已有 `通用-平台签约评估框架`
- ✅ 竞品分析 → 已有 `通用-分析竞对作品`

**但缺少一个"站在更高层级"的 Skill**：在进入上述所有具体设计工作之前，需要先完成项目级的战略决策与体系化初始化。这类似于软件工程中的"项目启动与架构设计阶段"——在写任何代码（大纲/正文）之前，先把需求、技术选型、架构方案定下来。

### 发现二：网文项目的成功要素可分为三层预先设计

从市场数据和行业分析来看，网文的成功高度依赖于**三层预先设计的质量**：

| 层级 | 核心问题 | 影响范围 |
| --- | --- | --- |
| 战略层 | 这个项目到底卖给谁？凭什么卖？ | 决定作品天花板 |
| 设计层 | 用什么套路组合、人设、金手指来实现承诺？ | 决定前中期吸引力 |
| 工程层 | 节奏怎么控制？付费点怎么埋伏笔？中段怎么防崩？ | 决定长期追读与付费 |

现有 Skill 主要集中在设计层（人物、设定、大纲）和工程层（节奏、钩子、审阅），但**战略层的决策没有系统化覆盖**——而这正是项目初始化的核心。

### 发现三：平台差异决定初始化时的关键选择

不同平台的读者画像差异显著（来源：纵横中文网编辑许斌访谈）：

| 平台 | 核心用户 | 特征 | 对初始化的影响 |
| --- | --- | --- | --- |
| 起点 | 平均22-23岁大学生 | 节奏更快但门槛高，付费意愿强 | 套路需要创新感，长线设计更重要 |
| 番茄 | 平均25-26岁 | 算法推荐，兼容并包，Z世代主导 | 开篇钩子密度高，短平快优先 |
| 七猫 | 接近30岁 | 无线文方向，四五十岁读者多 | 传统套路依然有效，战神文/赘婿文等 |
| 晋江 | 18-30岁女性为主 | 女频核心，情感驱动 | 情感线/CP感设计优先 |

这意味着项目初始化不能脱离平台"裸选"套路。同一个"先婚后爱"套路，在起点、晋江、七猫上的设计策略完全不同。

### 发现四：套路体系可分层分类，形成"套路组合矩阵"

从大量数据分析来看，网文套路可以解构为**五层体系**：

**第一层：叙事启动套路**——故事怎么开场

- 重生流、穿越流、系统流、觉醒流、退婚流、穿书流

**第二层：核心冲突套路**——故事靠什么驱动

- 先婚后爱、追妻火葬场、废柴逆袭、扮猪吃虎、复仇流、国运流、守国门

**第三层：持续驱动套路**——故事怎么维持

- 升级打怪流、解密探案流、打脸循环流、种田经营流、诸天副本流、幕后黑手流

**第四层：情感套路**——读者的情绪抓手

- 替身文学、白月光、破镜重圆、双向暗恋、追夫火葬场、哥哥文学

**第五层：反套路创新**——差异化竞争力

- 对传统套路的扭转、套路叠加融合、反常理的设定反转

第1-2层在**初始化阶段**就需要选定，第3层可以只是方向性规划（在分卷大纲中细化），第4层取决于题材（女频必须、男频可选），第5层是差异化武器。

**套路叠加策略**：顶级爆款通常采用"主套路+辅助套路"的组合。例如《大奉打更人》= 修仙升级（主）+探案解密（辅）+朝堂权谋（辅）。初始化阶段需要确定套路组合方案。

### 发现五：读者心理决策漏斗需要在初始化阶段预设防线

从读者行为研究来看，读者从接触作品到付费追读经历**7个决策关卡**，每个关卡都需要在初始化阶段预设策略：

| 关卡 | 读者决策 | 初始化需要预设 |
| --- | --- | --- |
| 曝光层 | 点不点开/划不划走 | 书名+封面策略 |
| 简介层 | 点不点开正文 | 简介核心钩子+平台适配 |
| 开头层 | 前300字留不留 | 异常前置/冲突前置策略 |
| 首章层 | 收不收藏 | 信息释放节奏+情绪波设计 |
| 养肥层 | 追不追读（前10章） | 回报率规划+中段钩子分布 |
| 付费层 | 值不值得付费 | 第1付费点设计+价值感预埋 |
| 长期层 | 100章后弃不弃书 | 中段防崩策略+新冲突导入 |

其中**曝光层→简介层→开头层**三个关卡在初始化阶段通过"书名+简介+前300字方案"完成预设；**首章层→养肥层**通过"前10章节奏蓝图"完成设计。

### 发现六：商业化验证需要在初始化阶段嵌入

很多作品写到上架才发现"没人看"，本质问题是初始化阶段的商业化验证缺失。需要在初始化阶段就做以下验证：

1. **市场空间验证**：所选"题材×套路×平台"组合是否有足够读者基数？
2. **差异化验证**：与竞品相比，核心差异点是什么？读者凭什么选你这本？
3. **开篇杀伤力验证**：书名→简介→开头是否在3秒内有抓力？
4. **付费意愿验证**：读者在前面10-20章内是否有继续读的理由？
5. **长期续航验证**：写到100万字时还有没有故事可讲？

## 八模块框架详解

基于上述发现，小说项目初始化应包含以下八个模块：

### 模块一：市场校准 —— 平台×题材×读者三角适配

**产出物**：《市场校准表》

| 决策项 | 内容 | 决策原则 |
|--------|------|---------|
| 平台确认 | 主攻平台 + 辅助分发平台 | 主攻平台决定核心策略 |
| 题材选定 | 大题材 + 细分子类型 | 大题材看趋势，子类型看创新空间 |
| 读者画像 | 年龄/性别/阅读场景/付费意愿 | 决定行文节奏与爽点类型 |
| 竞争定位 | 红海/蓝海/差异化空间 | 决定是否需要新手找创新点 |

**与现有Skill的关系**：输入来自 `通用-深度研究`（题材趋势/平台生态研究）；输入也来自 `通用-分析竞对作品`（竞品画像）。

### 模块二：核心定位 —— 核心理念与读者承诺

**产出物**：《一句话核心理念》

核心要素：
1. **核心卖点**：用一句话说清楚"这本书最特别的地方是什么"
   - 模板：一个[身份]在[背景]下，用[方式]做[目标]
   - 示例："一个刑警重生到三年前，在案件发生之前就开始布局"
2. **读者承诺**：读者读这本书能得到什么体验？
   - 示例："你会看到智商在线的破案+每一次反转都出乎意料"
3. **情绪主轴**：读完每一章，读者最强烈的情绪应该是什么？
   - 悬疑=紧张→解惑→还想知道更多
   - 爱情=心动→揪心→甜/虐
   - 爽文=憋屈→释放→满足

**与现有Skill的关系**：为 `通用-设计故事面` 提供输入；为 `通用-撰写内容简介` 提供核心素材。

### 模块三：读者心理学设计 —— 从曝光到付费的7关预设

**产出物**：《读者决策漏斗预设表》

需预设的内容：
1. **书名策略**（主书名+备选，参看 `通用-设计书名`）
2. **简介策略**（核心钩子+平台适配，参看 `通用-撰写内容简介`）
3. **前300字策略**（异常前置/冲突前置方案）
4. **前3章节奏蓝图**（信息释放+钩子+情绪波分布）
5. **前10章回报率规划**（读者在前10章内能得到什么）
6. **第1付费点设计**（什么时候读者愿意付费，值不值）
7. **中段防崩策略**（写到50万字时怎么维持）

**平台差异**：
- 七猫/番茄（免费平台）：前300字就要出钩子，3章内要有小爽点
- 起点（付费平台）：可以稍慢热，但要有信息密度和悬念钩子
- 晋江（情感向）：情感的"第一印象"要在前3章建立

### 模块四：套路组合 —— 五层套路矩阵设计

**产出物**：《套路组合方案》

决策步骤：
1. **选主套路**：选择核心冲突层的1个主套路（如先婚后爱、重生复仇）
2. **选启动方式**：选择叙事启动层的1种开场方式（如重生开始、从婚礼开始）
3. **选辅助套路**：从持续驱动层选择1-2个辅助套路（如经营+打脸）
4. **选情感抓手**：从情感套路层选择（女频必备，男频可选）
5. **选反套路点**：确定1-2个差异化创新点

**套路×平台适配参考**：
- 起点：适合"苟道流"、"稳健流"、"凡人流"等长线设计
- 番茄：适合"系统流"、"副本流"、"脑洞文"
- 七猫：适合"战神文"、"赘婿文"、"逆袭文"等传统套路
- 晋江：适合"先婚后爱"、"追妻火葬场"、"破镜重圆"

### 模块五：人设工程 —— 角色商业价值设计

**产出物**：《人设定位表》

核心决策：
1. **主角原型**：读者代入的锚点
   - 废柴流（起点→逆袭）
   - 天才流（压抑→突破）
   - 普通人流（真实感→共鸣）

2. **主角核心特质**：3-5个标签（如：腹黑、护短、智商在线、有底线、会成长）

3. **核心关系设计**：
   - CP/感情线设定（女频核心，男频辅助）
   - 金手指/导师角色（指引主角成长）
   - 主要对手/反派（制造冲突）
   - 伙伴/团队（辅助主线）

4. **人设差异化**：在同类题材中，这个角色有什么独特之处？

**与现有Skill的关系**：为 `通用-设计人物传记` 提供人物名单与核心定位。

### 模块六：金手指与力量体系 —— 核心竞争力设计

**产出物**：《金手指设计表》

金手指选择的五个维度（参考起点成神指南）：
1. **助力升级**：金手指是否能帮助主角持续变强？
2. **推动剧情**：金手指是否能驱动主角主动行动？
3. **适当包装**：形式是否与当前市场偏好匹配？
4. **限制条件**：是否有合理的代价/限制？（防止无敌）
5. **成长空间**：金手指本身能否进化？

**金手指类型矩阵**：
| 类型 | 适用题材 | 注意事项 |
| --- | --- | --- |
| 系统流 | 泛用，尤其男频 | 需创新包装，防千篇一律 |
| 重生/穿越 | 泛用，女频标配 | 信息差是核心爽感来源 |
| 天赋/血脉 | 玄幻/仙侠 | 需合理升级路径 |
| 宝物/道具 | 玄幻/修仙 | 防挂太强 |
| 老爷爷 | 修仙/玄幻 | 需设计退场机制 |
| 信息差 | 推理/悬疑/重生 | 防信息量不足 |

**力量体系设计**（如有等级体系）：
1. **等级划分**：清晰可感知（如炼气→筑基→金丹）
2. **突破条件**：每个阶段的升级需要什么？
3. **差异化**：主角凭什么比别人快/强？
4. **可视化**：读者能不能感受到"变强了"？

### 模块七：世界观预设定 —— 舞台与规则

**产出物**：《世界观初始化清单》

内容包括：
1. **时代/背景**：现代/古代/未来/架空
2. **核心矛盾**：世界层面的冲突（如：修仙资源不足、社会不公、末世危机）
3. **势力格局**：主要阵营/势力分布
4. **底层规则**：这世界有什么特殊的运行规则？
5. **氛围定调**：整体是黑暗/光明/轻松/沉重/悬疑？

**注意**：初始化阶段只做必要的"天花板"设定，具体细节交给 `通用-设计故事设定` 和 `通用-设计总大纲` 去丰富。

### 模块八：商业化验证 —— 项目可行性评估

**产出物**：《商业化验证清单》

验证项：
1. **目标平台匹配度**：这个项目适合目标平台吗？
2. **市场容量**：这个题材×套路组合的市场够大吗？
3. **差异化空间**：与TOP竞品相比，差异化够不够？
4. **长期续航**：能支撑多少字？100万字？200万字？
5. **IP转化潜力**：是否有影视/动漫/游戏改编空间？
6. **风险预警**：有什么可能导致失败的隐患？

**与现有Skill的关系**：可调用 `通用-平台签约评估框架` 做更细化的评估。

## 与现有Skill的协作路径

```
[项目初始化] ← 调用 → [深度研究]（题材/平台/读者研究）
     ↓                     [分析竞对作品]（竞品分析）
     ↓
     ├── 产出市场校准表 → 输入 → [设计题材定位框架]
     ├── 产出核心定位 → 输入 → [设计故事面]、[撰写内容简介]
     ├── 产出读者漏斗预设 → 输入 → [设计总大纲]（节奏规划）
     ├── 产出套路组合 → 输入 → [设计分卷大纲]（套路落地）
     ├── 产出入设定位 → 输入 → [设计人物传记]
     ├── 产出金手指/力量体系 → 输入 → [设计故事设定]
     ├── 产世界观初始化 → 输入 → [设计故事设定]、[设计总大纲]
     └── 产出商业化验证 → 调用 → [平台签约评估框架]
```

项目初始化是所有下游 Skill 的"上游输入源"——它不做具体设计，而是为所有设计工作提供决策依据。它回答"做什么、为什么做"，下游 Skill 回答"怎么做"。

## 诚实边界

### 信息截止日期
本研究报告基于2025-2026年上半年的公开资料。网文市场变化较快，具体数据（如平台用户画像、热门套路迭代）需要持续更新。

### 信息缺口
- 各平台**内部运营数据**（如具体题材的付费转化率、完读率）无法获取，结论基于公开榜单、行业报告和访谈的推断。
- 套路组合的"最佳实践"更多来自经验总结而非量化实验，不同作者的具体执行差异可能很大。
- 海外平台（WebNovel、GoodNovel等）的项目初始化需求与国内平台差异可能较大，本报告以国内市场为主。

### 不确定项
- 具体的最佳套路组合比例（如"打脸密度多少最合适"）因题材和平台而异，建议通过竞品分析具体校准。
- 读者漏斗各层的转化率（如"简介到开头的转化率"）无公开数据，属于经验估计。
- "中段防崩"的成功率高度依赖作者个人的剧情掌控能力，初始化阶段的策略只能降低风险不能消除风险。

### 置信度总评
**高**（整体框架与模块划分）。核心发现（八模块框架、五层套路体系、读者决策漏斗、平台差异影响）均有多个独立来源支撑，且与现有 Skill 体系形成逻辑闭环。具体数值和细节建议需要结合具体项目验证。

### 反常识声明
- **"不能上来就想大纲"**：常规认知是"写小说先写大纲"，但本框架建议大纲之前先做项目初始化。这与常见的"直接开写"或"先写大纲"的做法不同，但更符合商业网文"先做产品定义再做产品设计"的逻辑。
- **"套路越多越好是误区"**：常见说法是"要多套路叠加才精彩"，但研究显示初学者使用超过2-3个套路组合时，容易导致套路间的冲突和节奏失控。建议以"1主+1辅"起步。
