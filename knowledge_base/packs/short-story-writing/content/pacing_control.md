# 短篇小说节奏控制

## 核心原则

短篇小说节奏要**快而精**，每一章都要有明确目的。

## 短篇节奏公式

```
第1章：抛冲突 + 展金手指
第2-3章：小目标 + 小挫折 + 小成功
第4-6章：升级困难 + 人物关系深化
第7-8章：危机爆发 + 低谷
第9章：最终对决 + 高潮
第10章：收束 + 余韵
```

## 钩子设计

### 章头钩子
- 前300字必须有冲突或悬念
- 避免大段环境描写
- 直接进入故事

### 章尾钩子
- 每章结尾留钩子
- 类型：悬念/危机/反转
- 让读者想看下一章

### 钩子示例
- 悬念型："门外传来脚步声..."
- 危机型："他只有10分钟时间"
- 反转型："原来这一切都是..."

## 节奏变化

**紧张→缓和→紧张**

不要一直紧绷，给读者喘息空间

**示例**：
- 第1-2章：紧张（冲突爆发）
- 第3章：缓和（人物互动）
- 第4-5章：紧张（新冲突）

## 避免节奏问题

### ❌ 节奏太快
- 读者跟不上
- 情感铺垫不足

### ❌ 节奏太慢
- 读者失去耐心
- 水字数嫌疑

### ❌ 节奏单一
- 一直快或一直慢
- 没有变化

## 短篇节奏检查清单

- [ ] 每章有明确目标？
- [ ] 每章有钩子？
- [ ] 节奏有变化？
- [ ] 高潮在最后20%？
- [ ] 结局有满足感？
