# 短篇小说代入感塑造

## 核心原则

短篇小说必须在**前500字**内让读者代入，没有长篇的铺垫空间。

## 快速标签化

**原则**：前200字让读者记住主角

**方法**：核心标签 + 反差细节 = 活人

**示例**：
- 穷小子 + 隐藏的天才能力
- 冷面杀手 + 不为人知的温柔
- 乖乖女 + 叛逆的内心

## 五感代入

每个场景至少使用2种感官描写：

| 感官 | 描写示例 |
|------|----------|
| 视觉 | 具体的颜色、形状、光影 |
| 听觉 | 环境音、对话语气 |
| 嗅觉 | 食物、环境、季节 |
| 触觉 | 温度、质感、疼痛 |
| 味觉 | 食物、苦涩、甜蜜 |

## 情绪共鸣

**核心公式**：困境 → 挣扎 → 希望 → 得偿所愿

**技巧**：
- 让读者看到主角的努力和付出
- 让读者感受到主角的真实情感
- 让读者为主角的成功感到高兴

## N+1 原则

**定义**：新剧情开始时，先用熟悉的内容让读者代入

**方法**：
- 日常场景（起床、吃饭、聊天）
- 熟悉的物品和环境
- 读者能共鸣的情感

## 短篇代入感清单

- [ ] 前200字有主角标签？
- [ ] 前500字有冲突或悬念？
- [ ] 使用了2种以上感官描写？
- [ ] 读者能快速理解主角处境？
- [ ] 有引发共鸣的情感点？
