# 短篇小说人物设计

## 核心原则

短篇小说人物设计要**精简高效**，每个人物都要有明确的功能。

## 主角设定模板

```markdown
- 姓名：
- 年龄：
- 外貌（3个关键特征）：
- 性格标签（2-3个）：
- 核心欲望：
- 致命弱点：
- 金手指：
```

## 配角原则

**数量**：2-4个核心配角

**功能**：每个配角必须推动主线或展现主角某一面

**标签化**：每人一个鲜明标签
- 话痨型：缓解紧张气氛
- 冷面型：衬托主角热血
- 吃货型：增加生活气息

## 反派设计

**动机**：反派的行为必须有合理动机

**威胁**：反派必须让读者感到真实威胁

**结局**：反派的结局要有说服力

## 人物关系图

```
主角
├── 盟友1（功能：协助）
├── 盟友2（功能：衬托）
├── 反派（功能：冲突）
└── 导师（功能：指引）
```

## 人物塑造技巧

### 核心标签 + 反差细节
- 冷酷杀手 + 每次杀人后去孤儿院捐款
- 乖乖女 + 秘密的摇滚歌手身份
- 老好人 + 不为人知的复仇计划

### 展示不讲述
- ❌ "他很愤怒"
- ✅ "他捏碎了手中的茶杯，滚烫的茶水流过指缝"

### 对话塑造
- 每个角色说话方式不同
- 用口头禅和语气词区分角色
- 对话要有目的，不是闲聊
