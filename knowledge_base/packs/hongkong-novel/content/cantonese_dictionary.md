# 粤语词典与港式表达

## 常用粤语词汇

### 人称代词
- 我 → 我
- 你 → 你
- 他/她 → 佢
- 我们 → 我哋
- 你们 → 你哋
- 他们 → 佢哋

### 疑问词
- 什么 → 咩 / 乜
- 怎么 → 点 / 点解
- 为什么 → 点解 / 为咩
- 哪里 → 边度
- 谁 → 边个
- 多少 → 几多

### 常用动词
- 看 → 睇
- 来 → 嚟
- 去 → 去
- 说 → 讲
- 吃 → 食
- 喝 → 饮
- 睡 → 训
- 走 → 行
- 跑 → 走
- 想 → 谂
- 知道 → 知
- 有 → 有
- 没有 → 冇
- 是 → 系
- 不是 → 唔系

### 常用形容词
- 好 → 好 / 靓
- 坏 → 差 / 衰
- 大 → 大
- 小 → 细
- 快 → 快
- 慢 → 慢
- 热 → 热
- 冷 → 冻
- 多 → 多
- 少 → 少

### 常用副词
- 很 → 好 / 几 / 超
- 非常 → 真系 / 简直
- 马上 → 即刻 / 马上
- 突然 → 忽然 / 猛地
- 已经 → 已经 / 已
- 还 → 仲
- 就 → 就
- 也 → 都

### 语气词
- 啦 → 表示肯定或催促
- 嘛 → 表示理由或撒娇
- 呢 → 表示疑问或强调
- 啊 → 表示感叹
- 哦 → 表示明白
- 喔 → 表示提醒
- 咯 → 表示肯定
- 咩 → 表示疑问
- 嘅 → 表示所属
- 㗎 → 表示肯定
- 啵 → 表示感叹

### 港式英语
- OK → 好
- Cool → 酷
- Sorry → 对唔住
- Thanks → 多谢
- Bye → 拜拜
- Man → 男人
- Guy → 家伙
- Boss → 老板
- Check it out → 睇下
- No problem → 冇问题

## 港式场景描写

### 茶餐厅
- 菠萝油、奶茶、蛋挞、云吞面
- 卡座、吊扇、玻璃门、菜单牌
- 服务员叫"伙计"，结账叫"埋单"

### 的士
- 的士站、招手、打表
- 司机叫"的士佬"
- 说"去XX地方"

### 警署
- 报案室、审讯室、拘留室
- 警员、督察、高级督察
- "你有权保持沉默"

### 社团堂口
- 堂主、大佬、兄弟
- 拜关公、歃血为盟
- "出来混，讲的是义气"

## 港式俗语
- 唔该 → 谢谢 / 麻烦你
- 唔好意思 → 不好意思
- 冇问题 → 没问题
- 好嘢 → 好东西 / 太好了
- 坏咗 → 坏了
- 靓仔 → 帅哥
- 靓女 → 美女
- 老细 → 老板
- 伙计 → 服务员
- 埋单 → 结账
