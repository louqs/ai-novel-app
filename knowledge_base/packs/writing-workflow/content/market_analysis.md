## 四、发布策略

### 发布时机

**最佳发布时间：**
- 工作日：周二、周三
- 时间段：上午10点、晚上8点
- 避开：周一、周五

**字数要求：**
- 首发最低：2万字
- 推荐首发：5-10万字
- 最佳首发：10万字以上

### 发布节奏

**新手推荐：**
```
首发：5万字（约15-20章）
日更：4000字（约2章）
存稿：保持3-5章存稿
```

**进阶推荐：**
```
首发：10万字（约35-40章）
日更：6000字（约3章）
存稿：保持5-10章存稿
```

### 数据关注

**关键指标：**
- 完读率：>30%为良好
- 留存率：>50%为良好
- 追读人数：持续增长
- 评论互动：积极正面
