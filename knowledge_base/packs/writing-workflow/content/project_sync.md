# 项目文件同步指南

## 核心工作流

### 1. 定位项目根目录

```
搜索顺序：
1. 当前工作目录是否有 `项目文件/` 或 `project-files/`
2. 当前工作目录是否有 `正文卷/` 或 `chapters/`
3. 向上查找最近的项目文件集合
```

### 2. 读取新章节内容

- 读取最新创建或修改的章节文件
- 提取关键信息：
  - 章节号和标题
  - 主要事件和剧情推进
  - 新出现的人物和关系变化
  - 新获得的资源和能力变化
  - 新埋下的伏笔和悬念
  - 当前时间点和地点

### 3. 同步更新项目文件

#### 更新 progress.md

```markdown
更新内容：
- 标记该章节状态为 ✅已完成
- 记录字数
- 填写主要事件摘要
- 更新整体完成度百分比
```

#### 更新 99_当前状态卡.md

```markdown
更新内容：
- 当前章节：更新为下一章待写
- 当前场景：更新为新章节结尾场景
- 主角状态：根据新章节内容更新
- 金手指状态：如有变化则更新
- 人物关系：更新新增或变化的关系
- 资源边界：更新新获得的资源
- 当前必须推进的事：更新下一步任务
```

#### 更新伏笔追踪

```markdown
更新内容：
- 记录新章节埋下的伏笔
- 更新已埋下伏笔的状态（如已回收）
- 添加新的悬念钩子
- 更新解决计划
```

### 4. 一致性检查

完成文件同步后，执行以下检查：

| 检查项 | 检查内容 |
|--------|----------|
| 人物OOC | 主角和主要配角的行为是否符合人设 |
| 时间线 | 当前时间是否与设定一致 |
| 资源连续性 | 获得的资源是否在后续章节中连续 |
| 金手指限制 | 金手指使用是否超出设定限制 |
| 年代准确性 | 年代文元素是否与设定的年代一致 |
| 伏笔连续性 | 前文伏笔是否有回收或推进 |

### 5. 输出同步报告

```markdown
## 📋 项目文件同步报告

### 已更新文件
- [x] progress.md - 第X章标记完成
- [x] 99_当前状态卡.md - 状态同步至第X章结尾
- [x] 伏笔追踪 - 新增X个伏笔

### 新章节摘要
- **章节**：第X章 XXX
- **字数**：约XXXX字
- **主要事件**：...
- **人物变化**：...

### 一致性检查
- 人物OOC：✅ 无异常
- 时间线：✅ 连续
- 金手指：✅ 合理使用

### 下一步建议
- 继续写第X+1章
- 建议关注：...
```
