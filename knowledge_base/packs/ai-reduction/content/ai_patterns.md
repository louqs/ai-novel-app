# AI写作模式与破坏方法

## AI写作的典型特征

### 1. 对称结构
**AI特征**：喜欢用对称的句式和结构
**破坏方法**：
- 打破对称，用不对称的表达
- 长短句交替，不要都是相同长度
- 偶尔用破句、省略句

### 2. 规律排比
**AI特征**：喜欢用排比句式
**破坏方法**：
- 打破排比，用不同的句式
- 偶尔用重复代替排比
- 加入一些"跑题"的内容

### 3. 完美逻辑
**AI特征**：逻辑过于完美，没有跳跃
**破坏方法**：
- 加入一些跳跃，不要太连贯
- 偶尔用括号、破折号打断叙述
- 加入一些"废话"和重复

### 4. 模板化表达
**AI特征**：用词和句式过于模板化
**破坏方法**：
- 换更口语化的表达
- 加入方言和语气词
- 用更具体的词汇

### 5. 中性语气
**AI特征**：语气过于中性，没有情绪
**破坏方法**：
- 加入情绪化的表达
- 用感叹句、反问句
- 加入人物的内心吐槽

---

## 破坏AI模式的具体方法

### 1. 增加"小瑕疵"
- 偶尔的口误
- 重复说某些话
- 不那么精准的表达

### 2. 增加跳跃
- 思维的跳跃
- 场景的快速切换
- 时间的压缩或扩展

### 3. 增加重复
- 真人会重复说某些话
- 偶尔的强调性重复
- 口语中的习惯性重复

### 4. 增加"废话"
- 符合日常说话习惯的废话
- 一些无关紧要的细节
- 生活化的小动作

### 5. 增加感官细节
- 视觉：具体的颜色、形状、光影
- 听觉：具体的声音、音调、节奏
- 嗅觉：具体的气味、浓度
- 触觉：具体的温度、质感、湿度

## 常见AI模式速查表

| AI模式 | 破坏方法 |
|--------|---------|
| "首先...其次...最后" | 打破顺序，用不同的连接方式 |
| "随着...就在这时" | 用更自然的过渡 |
| "他感到..." | 用身体反应代替 |
| "这意味着..." | 删除，让读者自己理解 |
| "突然..." | 用更具体的描述 |
| "缓缓地..." | 换更具体的动词 |
| "深深地..." | 换更具体的程度词 |
| "不禁..." | 用更自然的表达 |
