# 中篇小说人物关系网

## 核心原则

中篇小说需要完整的人物关系网，增加故事深度。

## 核心人物结构

```
主角
├── 盟友1（功能：协助 + 衬托）
├── 盟友2（功能：情感线 + 支持）
├── 导师（功能：指引 + 传承）
├── 反派1（功能：直接冲突）
└── 反派2（功能：幕后黑手）
```

## 人物关系图

```
主角 ←→ 盟友1：信任关系

主角 ←→ 导师：师徒关系
```
