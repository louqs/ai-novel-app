# 中篇小说伏笔系统

## 核心原则

中篇小说需要完整的伏笔系统，保持读者期待感。

## 伏笔生命周期

```
铺设 → 推进 → 回收
```

## 伏笔管理模板

```markdown
| 伏笔ID | 描述 | 铺设章节 | 推进章节 | 回收章节 | 状态 |
|--------|------|----------|----------|----------|------|
| F001 | 主角身世之谜 | 第1章 | 第10章 | 第25章 | 已回收 |
| F002 | 神秘组织 | 第5章 | 第15章 | 第40章 | 进行中 |
| F003 | 导师的秘密 | 第3章 | 第20章 | 第45章 | 进行中 |
```

## 伏笔原则

### 每卷至少3个伏笔
- 保持悬念连续性
- 给读者期待感
- 增加阅读动力

### 每5章推进一次
- 保持读者记忆
- 避免伏笔遗忘
- 增加紧迫感

### 回收要有满足感
- 不能虎头蛇尾
- 要有情感冲击
- 要有逻辑闭环

## 伏笔类型

### 剧情伏笔
- 主角身世
- 反派阴谋
- 世界秘密

### 人物伏笔
- 盟友真实身份
- 反派动机
- 导师秘密

### 物品伏笔
- 神秘物品
- 关键道具
- 遗产传承

## 伏笔检查清单

- [ ] 每卷有3+个伏笔？
- [ ] 伏笔每5章推进一次？
- [ ] 回收有满足感？
- [ ] 无遗漏伏笔？
- [ ] 逻辑闭环？
