# 冲突设计技巧

## 一、冲突的本质

冲突 = 欲望 + 障碍

- 主角想要什么？（欲望）
- 什么阻止了他？（障碍）
- 他如何克服？（行动）

## 二、冲突的层次

### 1. 外部冲突
- 人与人的冲突（反派、对手）
- 人与环境的冲突（自然灾害、社会环境）
- 人与事件的冲突（意外、危机）

### 2. 内部冲突
- 人与自我的冲突（恐惧、犹豫、道德困境）
- 人与欲望的冲突（贪念 vs 理智）
- 人与过去的冲突（创伤、遗憾）

### 3. 关系冲突
- 亲情冲突（家庭矛盾、代沟）
- 爱情冲突（误会、背叛、第三者）
- 友情冲突（利益、背叛、误解）

## 三、冲突设计公式

### 黄金三章冲突

1. **第一章**：抛出主冲突（主角面临什么困境）
2. **第二章**：亮出主角的特殊优势或系统（金手指）
3. **第三章**：锁定短期目标（读者知道主角要做什么）

### 单章冲突

- 开篇：冲突爆发
- 中段：冲突升级
- 结尾：冲突暂时解决或留下悬念

## 四、冲突升级技巧

### 1. 时间压力
- 倒计时：24小时内必须完成
- 截止日期：月底前必须解决

### 2. 资源限制
- 金钱不足
- 人手不够
- 时间不够

### 3. 多重障碍
- 解决一个问题，又出现新问题
- 内忧外患同时爆发

### 4. 反派升级
- 反派越来越强
- 反派背后还有更大的反派

## 五、常见冲突毒点

### 1. 冲突太弱
- 读者感觉不到紧张感
- 解决问题太容易

### 2. 冲突太假
- 不符合逻辑
- 为了冲突而冲突

### 3. 冲突太重复
- 同样的冲突模式反复出现
- 读者产生审美疲劳

### 4. 冲突无后果
- 冲突解决了但没有代价
- 读者感觉不到重量

## 六、冲突设计检查清单

- [ ] 冲突是否有足够的紧迫感？
- [ ] 冲突是否符合角色动机？
- [ ] 冲突是否有合理的解决方案？
- [ ] 冲突解决后是否有代价？
- [ ] 冲突是否推动了剧情发展？
- [ ] 冲突是否展现了角色成长？
