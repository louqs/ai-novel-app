# 项目文件结构

## 文件结构模板

```
小说名称/
├── 项目文件/
│   ├── 小说大纲.md              # 核心设定、故事大纲、章节规划
│   ├── 人物设定.md              # 主角、配角、反派详细设定
│   ├── 99_当前状态卡.md         # 当前进度、主角状态、创作追踪
│   ├── 进度追踪.md              # 章节完成进度、脚本检查状态
│   ├── 文件索引.md              # 所有文件索引、快速查找
│   ├── 伏笔追踪.md             # 伏笔状态、强度、期待感评分
│   ├── 弧线摘要.md             # 弧线摘要
│   ├── 章节分析.md             # 章节分析记录
│   ├── 角色关系.md             # 动态人物关系图
│   ├── 角色状态.md             # 角色心理/存活状态+章节号防覆盖
│   ├── 资源账本.md             # 现金/药材/物资追踪
│   ├── 战力跟踪.md             # 战力等级/金手指状态
│   ├── 剧情线索.md             # MT线索管理
│   ├── 时间线.md               # 故事时间/天气/地点
│   ├── 职业跟踪.md             # 角色职业阶段+技能等级
│   └── 组织关系.md             # 组织势力+成员+据点
├── 正文卷/
│   └── 第X章_*.md             # 章节正文文件
└── README.md                  # 本文件
```

## 文件说明

### 核心文件（必须）

| 文件 | 用途 | 更新频率 |
| --- | --- | --- |
| 小说大纲.md | 设定总索引：核心设定、故事简介、人物小传、章节规划 | 项目开始时 |
| 人物设定.md | 主角、配角、反派的详细设定（背景、性格、金手指、成长弧光） | 项目开始时 |
| 99_当前状态卡.md | 当前时间点、主角状态、金手指状态、人物关系、资源边界、创作追踪 | 每章更新 |
| 进度追踪.md | 章节完成状态、字数、里程碑、资源追踪、感情线进度 | 每章更新 |

### 追踪文件（每章更新）

| 文件 | 用途 |
| --- | --- |
| 资源账本.md | 资源账本：现金收支、药材库存、物资、人脉、能力 |
| 角色关系.md | 动态人物关系图：关系变化追踪 |
| 角色状态.md | 角色心理/存活状态+章节号防覆盖 |
| 战力跟踪.md | 战力跟踪：金手指等级、技能变化、能力合理性 |
| 时间线.md | 时间线：故事日期、事件、天气、地点、时间连续性 |
| 伏笔追踪.md | 伏笔状态、强度、超期检测、期待感评分、最佳兑现章节 |
| 职业跟踪.md | 角色职业阶段+技能等级提升 |

### 节奏规划文件（按卷更新）

| 文件 | 用途 |
| --- | --- |
| 第一卷节奏规划.md | 第1-10章挫折→高潮节奏规划 |
| 第二卷节奏规划.md | 第11-20章挫折→高潮节奏规划 |
| 第三卷节奏规划.md | 第21-30章挫折→高潮节奏规划 |

## 使用流程

### 1. 开新项目
1. 复制模板并创建文件
2. 填写核心设定（小说大纲.md）
3. 创建人物设定（人物设定.md）
4. 初始化状态卡（99_当前状态卡.md）

### 2. 写正文
1. 读取状态卡、任务计划
2. 按8条铁律写作
3. 自动执行内容检查（毒点/战力/时间线/一致性）
4. 自动更新所有项目文件

### 3. 检查与优化
1. 降重处理+AI检测+毒点检测
2. 冲突规划未来10-20章冲突分布
3. 市场分析热门题材和收益

## 注意事项

1. **资源同步**：每章写完后必须更新资源账本，避免资源不连续
2. **伏笔追踪**：埋下伏笔时记录到伏笔追踪，回收时标记状态
3. **人物关系**：关系变化时更新角色关系
4. **战力跟踪**：金手指/能力变化时更新战力跟踪
5. **时间线**：确保故事时间连续，检查天气合理性
6. **8条铁律**：写作时直接应用8条铁律
