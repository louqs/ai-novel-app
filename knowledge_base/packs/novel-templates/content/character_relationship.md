# 角色关系系统

## 亲密度说明

- **范围**：-100 到 +100
- **正向**：0-100，正派关系
- **负向**：-100-0，敌对关系
- **调整**：基于关键词自动计算

## 存活状态

| 状态 | 含义 | 级联影响 |
|------|------|---------|
| active | 活跃 | - |
| deceased | 已死亡 | 关系标记为past，组织身份标记为deceased |
| missing | 失踪 | 关系标记为past，组织身份标记为retired |
| retired | 退场 | 关系标记为past |

## 章节号防覆盖机制

**核心原则**：更新角色状态时，新章节号必须 ≥ 已记录的章节号，否则跳过更新

```
防覆盖规则：
- 心理状态：state_updated_chapter 新值 < 旧值 → 跳过
- 存活状态：status_changed_chapter 新值 < 旧值 → 跳过
```

## 性格漂移检测

每章写完后检查角色行为是否符合性格锚点：

| 角色 | 性格锚点 | 本章行为 | 漂移风险 |
|------|----------|----------|----------|
| 主角 | [锚点1, 锚点2] | [描述本章行为] | 🟢/🟡/🔴 |

- 🟢 无漂移，符合锚点
- 🟡 轻微漂移，可接受
- 🔴 明显漂移，需要修改
