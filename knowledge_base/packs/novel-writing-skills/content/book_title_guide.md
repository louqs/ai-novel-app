# 书名创作指南

## 书名的重要性

书名是小说的第一张名片，是吸引读者点击的关键因素。一个好的书名能够：
- 快速传递核心卖点
- 吸引目标读者群体
- 提高作品的曝光率和转化率
- 为作品奠定基调

## 书名创作原则

1. **字数控制**：尽量在15字以内，太长容易被算法截断
2. **关键词精准**：把"重生、系统、战神、赘婿、退婚、打脸"等热门词塞进去，方便平台推荐
3. **内容相关**：书名要和内容强相关，否则读者点进去发现货不对板，会直接弃书
4. **信息清晰**：避免过于文艺、信息模糊的书名，确保3秒内能看懂核心卖点

## 常见书名格式

### 1. 身份反差型（扮猪吃虎）
**公式**：弱势身份+强势行为/结果

**常见句式**：
- 《出狱当天，千亿财阀排队接我回家》
- 《夫人每天都在捂马甲》
- 《史上最弱修仙者》

### 2. 行为反差型（反套路）
**公式**：常规任务/身份+离谱操作

**常见句式**：
- 《让你当兵戒网瘾，你成就黑客帝国》
- 《开局被离婚，我反手娶了女总裁》

### 3. 结果反差型（打脸爽文）
**公式**：前期被虐/被轻视+后期打脸/逆袭

**常见句式**：
- 《离婚后，前夫跪求我回头》
- 《被赶出府，她身穿嫁衣扭头嫁残王》

### 4. 数字对比型（极端反差）
**公式**：极端数字+反常识结果

**常见句式**：
- 《1秒亏光500万，我靠摆摊年入3亿》
- 《修仙五分钟，无敌两千年》

### 5. 情绪/悬念型（情绪钩子）
**公式**：痛点/悬念+爽点/反转

**常见句式**：
- 《领导让我背黑锅，我反手把他送上热搜》
- 《算命的说我28岁必死，当晚我绑定了续命系统》

### 6. 系统/金手指型（脑洞反转）
**公式**：普通身份+离谱系统/金手指

**常见句式**：
- 《每天签到1㎡，90天后我买下整栋楼》
- 《开局快递奖励10个亿》

### 7. "题材 + 金手指 + 爽点"型（信息密度拉满）
**公式**：题材 + 金手指 + 爽点

**示例**：
- 《四合院：融合万兽，截胡娄晓娥》
- 《末世：开局觉醒SSS级掠夺天赋，我即是天灾》

## 书名公式

**题材 + 核心爽点 + 主角行为/身份**

### 示例
- 《重生之都市修仙》：重生 + 都市 + 修仙
- 《神级龙卫》：神级 + 龙 + 卫
- 《透视小医圣》：透视 + 小医 + 圣
