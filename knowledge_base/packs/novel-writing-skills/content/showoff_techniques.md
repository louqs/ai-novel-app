# 装逼创作原则

## 装逼的本质

装逼是在写主角与社会认知的冲突，是作者论证主角社会地位提高的过程。

## 装逼的核心机制

- **明暗线失衡**：主角实力分为两个维度——明线（战力体系晋升）和暗线（社会认知定位）
- **冲突产生**：明线实力高于暗线社会认知时，就会产生冲突
- **冲突解决**：通过主角解决反派这件事去震惊身边人，刷新对主角的认知
- **暗线拉高**：第六幕余波落幕，暗线拉高到与明线一致

## 正确的装逼方式

- 不是主角主动去证明"我很强"
- 是反派作为代理人撞到主角的枪口上
- 是环境、他人、时间告诉社会"你确实变强了"
- 通过侧面描写提高配角对主角的认知

## 错误的装逼方式

- "扮猪吃虎"：强者扮演弱者诱惑配角欺负然后反击，这本质是强者欺负弱者，在理论上不成立

## 爽感的来源

| 爽感类型 | 回答的问题 |
|----------|-----------|
| 升级 | "我能变强吗" |
| 碾压 | "我够强吗？" |
| 装逼 | "我的强被认可了吗？" |
| 复仇 | "不公会被纠正吗？" |
| 绝境逃亡 | "我能逃亡吗？" |
| 种田 | "弱者该如何变强？" |
| 苟道 | "弱者该如何生存？" |

## 驱动读者欲望的本质逻辑

### 核心公式
**生产诉求 → 给予希望 → 努力解决 → 得偿所愿**

### 生产诉求
- **定义**：用一种"低地位"、"困境"、"迫在眉睫的威胁"、"不曾拥有的事物"、"一辈子也无法到达的终点"这类让读者能够感同身受，且不爽的内容
- **本质**：读者看到让人厌恶的事情，心中天生会生出"不该如此"的念头
- **驱动力来源**：
  - "不该如此"的遗憾（如龙族、战锤、四合院、大明等经典题材）
  - "悬而未决"的处境（如表白未决等）

### 给予希望
- **定义**：金手指，即让读者看到改变困境的希望
- **金手指的本质**：现实中我们难以拥有的特质、能力

### 努力解决
- **节奏控制**：小说不能让读者这么快的"得偿所愿"
- **主流写法**：
  1. **逐渐变好**：将目标拆分为多个阶段
  2. **新的困境**：解决一个困境，又会遇到新的困境

### 得偿所愿
- **节奏的本质**：不断解决现有的矛盾，不断制造新的矛盾
- **好的节奏把控**：
  - 困境的层级都是在层层提高
  - 困境的难度、复杂度需要逐步提升
  - 困境的种类也需要不尽相同
