# 人物塑造深度指南

## 一、人物立体化公式

**核心标签 + 反差细节 = 活人**

### 示例
- 核心标签：冷酷杀手
- 反差细节：每次杀人后会去孤儿院捐款
- 结果：有血有肉的角色，不是脸谱化的反派

## 二、人物构建六步法

1. 搞清这个人物在故事里承担什么功能
2. 明确背景、阶层、欲望、恐惧、伤口、骄傲、资源、当前利益
3. 决定这些东西如何影响他的说话节奏、动作习惯、风险偏好
4. 加反差、加阴影、加灰度，拒绝脸谱化
5. 让人物变化绑定到具体事件，不空转
6. 每遇到重要情节都回头复查人设有没有偏

**角色行为公式：** 过往经历 + 当前利益 + 性格底色

## 三、配角独立化（避免工具人）

每个有用配角必须能回答：

1. **他想要什么？**（明确的目标）
2. **他害怕什么？**（底线/弱点）
3. **他的立场是什么？**（在冲突中选哪边）
4. **他为自己的利益做了什么？**（不是帮主角，是帮自己）
5. **如果主角不在场，他会做什么？**（独立于主角的剧情）

## 四、反派塑造

### 反派的自我逻辑

反派不觉得自己是反派。他的行为在自己看来完全合理。

**写反派前必须回答三个问题：**
1. 他想要什么？（必须是具体的、可以理解的东西）
2. 他为什么不能通过正常手段得到？
3. 他认为"正义"是什么？（他自己定义的那套）

### 反派话术（高级 vs 低级对照）

**❌ 低级（混混型，禁用）：**
- "你小子别不识抬举！"
- "咱们走着瞧！"
- 气急败坏指着鼻子骂

**✅ 高级（笑面虎型，推荐）：**
- 表面客气："大山兄弟有骨气是好事。但做生意光有骨气可不够。"
- 绵里藏针："俺们恒昌背后可是有人的，县城都有路子。"
- 笑里藏刀："山路不好走，以后可得当心脚下。"

## 五、NPC态度渐变

群体态度不能一步到位，必须有人带头、有人观望、有人质疑。

| 阶段 | 表现 | 过渡条件 |
|------|------|----------|
| 排斥/怀疑 | "这小子能行？" | - |
| 观望 | "先看看再说" | 1-2 次成功案例 |
| 半信半疑 | "好像有点本事" | 3 次以上成功+口碑传播 |
| 认可 | "大山有两下子" | 亲眼见证+利益相关 |
| 支持 | "大山的事就是咱的事" | 多次受益+感情积累 |

**每个 NPC 至少经过 3 个阶段才能从排斥到支持**，必须有具体事件触发。

## 六、角色亲密度调整参考

| 事件类型 | 变化 | 示例 |
|----------|------|------|
| 共同对敌 | +15~+20 | 一起面对敌人 |
| 日常友好 | +5~+10 | 一起做事、送饭 |
| 重大帮助 | +10~+15 | 救命、解决关键困难 |
| 真诚表露 | +5~+10 | 吐露心事、表达信任 |
| 误会/争吵 | -10~-15 | 被误解、争吵 |
| 背叛/出卖 | -20~-40 | 背后捅刀 |
| 敌对行动 | -5~-10 | 日常找茬 |

**亲密度影响互动方式：** <-30 敌意明显 / -30~0 疏远 / 0~30 普通 / 30~60 友好 / >60 亲密
