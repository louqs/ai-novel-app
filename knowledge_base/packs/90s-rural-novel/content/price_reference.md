# 90年代物价与收入参考

## 物价检查 ⭐⭐⭐⭐⭐（最重要）

### 食物价格（1990年）
- 大米：**0.2-0.35元/斤**
- 面粉：**0.18-0.3元/斤**
- 猪肉：**2.3-2.8元/斤**
- 鸡蛋：**1.5-2.8元/斤**
- 土豆/白菜：**0.1-0.2元/斤**
- 一碗面：**0.5-1元**

### 日用品价格（1990年）
- 一件衣服：**10-30元**
- 孩子学费（农村小学）：**4-10元/学期**

### 耐用品价格（1990年）
- 黑白电视：**400-800元**
- 彩色电视：**3000元左右**（稀罕物）
- 摩托车（国产）：**1700-3250元**
- 摩托车（进口）：**7000-16800元**
- 电话安装费：**5000元**（2年工资）

## 收入检查 ⭐⭐⭐⭐⭐（最重要）

### 全国收入水平（1990年）
- 全国农民人均纯收入：**686.3元/年**（国家统计局）
- 农村贫困线：**300元/年**（8500万人低于此线）
- **底层农户现金收入**：**200-400元/年**（扣除成本后）
- 城镇职工月工资：**125-180元/月**

### 赚钱速度参考
- 第一个月：**50-100元**合理
- 半年：**500-1000元**合理
- 一年：**1000-3000元**就是村里首富
- **1万元 = 万元户，全县有名**

## 常见错误清单

| 错误 | 正确 |
|------|------|
| 90年代一碗面10块钱 | 90年代一碗面0.5-1元 |
| 90年代一斤肉20块钱 | 90年代一斤肉2.3-2.8元 |
| 主角一个月赚10万 | 主角一年赚1000-3000元就是首富 |
| 底层农户年入几万 | 底层农户年现金收入200-400元 |
| 90年代大米2元/斤 | 90年代大米0.2-0.35元/斤 |
| 90年代家家有摩托车 | 90年代农村每百户只有0.8辆 |
| 90年代随便装电话 | 90年代电话安装费5000元（2年工资） |

## 物品和技术检查

### 稀罕物（1990年代初）
- 手机（大哥大）：非常罕见，价格1-2万元
- 彩色电视：还是稀罕物，价格3000元左右
- 洗衣机/冰箱：高档耐用品
- 摩托车：农村每百户只有0.8辆，是真正的奢侈品

### 普及时间线
- BB机：1990年代中期开始普及
- 互联网：1990年代末才开始
- 粮票取消：1993年

## 政策和历史事件

### 重要政策
- 家庭联产承包责任制：1980年代初开始
- 市场经济改革：1992年邓小平南巡后加速
- 粮票取消：1993年

### 社会环境
- 供销社：1990年代初还存在
- 乡镇企业：1990年代开始兴起
- 打工潮：1990年代开始大规模出现
- 合作医疗：1990年代逐步瓦解，看病主要靠自费

## 农村住房

### 住房等级
- 贫困农户：土坯墙、茅草顶、泥土地
- 普通农户：砖墙、瓦顶、部分水泥地
- 富裕农户：砖混结构、水泥地、有窗户玻璃
- 农村盖一栋新房：**1-2万元**
