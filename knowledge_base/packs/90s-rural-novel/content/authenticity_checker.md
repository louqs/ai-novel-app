# 90年代真实性检查清单

## 检查维度

### 1. 物价检查 ⭐⭐⭐⭐⭐（最重要）

**食物价格（1990年）**
- [ ] 大米价格是否为0.2-0.35元/斤？
- [ ] 猪肉价格是否为2.3-2.8元/斤？
- [ ] 一碗面是否为0.5-1元？

**日用品价格（1990年）**
- [ ] 一件衣服是否为10-30元？
- [ ] 孩子学费是否为4-10元/学期？

**耐用品价格（1990年）**
- [ ] 黑白电视是否为400-800元？
- [ ] 摩托车（国产）是否为1700-3250元？

### 2. 收入检查 ⭐⭐⭐⭐⭐（最重要）

- [ ] 农民人均纯收入是否为686.3元/年？
- [ ] 底层农户现金收入是否为200-400元/年？
- [ ] 赚钱速度是否合理？（一年1000-3000元就是村里首富）
- [ ] 万元户是否全县有名？

### 3. 物品和技术检查 ⭐⭐⭐

- [ ] 手机（大哥大）是否非常罕见（1-2万元）？
- [ ] BB机是否在1990年代中期才普及？
- [ ] 互联网是否在1990年代末才开始？
- [ ] 彩色电视是否还是稀罕物（3000元左右）？
- [ ] 摩托车是否是奢侈品（农村每百户只有0.8辆）？

### 4. 政策和历史事件检查 ⭐⭐⭐

- [ ] 家庭联产承包责任制是否在1980年代初开始？
- [ ] 市场经济改革是否在1992年邓小平南巡后加速？
- [ ] 粮票是否在1993年取消？
- [ ] 具体年份的重大事件是否准确？

### 5. 社会环境检查 ⭐⭐

- [ ] 供销社是否在1990年代初还存在？
- [ ] 乡镇企业是否在1990年代开始兴起？
- [ ] 打工潮是否在1990年代开始大规模出现？
- [ ] 合作医疗是否在1990年代逐步瓦解？

### 6. 农村住房检查 ⭐⭐

- [ ] 贫困农户住房是否为土坯墙、茅草顶、泥土地？
- [ ] 普通农户住房是否为砖墙、瓦顶、部分水泥地？
- [ ] 富裕农户住房是否为砖混结构、水泥地、有窗户玻璃？
- [ ] 农村盖一栋新房是否为1-2万元？

## 常见错误速查

| 错误 | 正确 |
|------|------|
| 90年代一碗面10块钱 | 90年代一碗面0.5-1元 |
| 90年代一斤肉20块钱 | 90年代一斤肉2.3-2.8元 |
| 主角一个月赚10万 | 主角一年赚1000-3000元就是首富 |
| 底层农户年入几万 | 底层农户年现金收入200-400元 |
| 90年代大米2元/斤 | 90年代大米0.2-0.35元/斤 |
| 90年代家家有摩托车 | 90年代农村每百户只有0.8辆 |
| 90年代随便装电话 | 90年代电话安装费5000元（2年工资） |

## 检查流程

1. **写前检查**：确认本章涉及的年代和物价
2. **写中检查**：遇到物价/收入时立即核实
3. **写后检查**：通读全章，检查所有数字是否合理
4. **定期检查**：每10章做一次全面真实性检查
