# 前3章冲突架构诊断卡

> 来源：8份AI开篇评价的交叉共识（2026-06-11），提炼为跨题材通用审阅项
> 适用范围：所有题材的Ch1-3审阅——冲突性质诊断、对抗性人物密度、追读期待感
> 注意：本文件与 `章节数据看板与阶段达标线.md` 互补——后者管"数字指标"，本文件管"结构质量"

---

## 一、冲突性质：现在时 vs 过去时（P0级）

这是最常见的"写得不好看但作者不自知"的问题。

| 诊断项 | 判断标准 | 红灯 |
| --- | --- | --- |
| **现在时冲突占比** | Ch1-3中，冲突以"读者正在目睹的外部事件"形式出现的比例 | < 50% |
| **过去时冲突占比** | 冲突以角色回忆/内心闪回/独白解释的形式出现 | > 50% |
| **见证 vs 听说** | 读者是在"现场观看"冲突发生，还是在"听角色回忆"曾经发生的事 | 核心伤害节点全部来自回忆 |

**为什么这是P0级问题**：网文读者的留存靠"我想知道接下来发生什么"——而不是"我想知道他过去经历了什么"。

**修正方向**：至少保留一两个关键伤害节点以现在时发生。如果Ch1的核心冲突是"女主被丈夫冷落三年"，不要在Ch1用三段回忆来解释——改成在Ch1**当场**让丈夫做一件体现冷落的事。

## 二、对抗性人物在场密度（P1级）

| 诊断项 | 判断标准 | 红灯 |
| --- | --- | --- |
| Ch1对立人物数 | 与主角立场相反、且出现在当前场景的外部人物数量 | = 0 |
| Ch3结束时对立人物总数 | Ch1-3中累计出场的对抗性人物 | ≤ 1 |
| 对抗性人物的行动 | 那个敌对人物是否在**当前场景**中对主角产生了压力/攻击/威胁 | 对抗性人物只在对话中被提及，从未亲自行动 |
| 主角对攻击的回应 | 主角是否对外部攻击做出了反应（反击/对峙/策略性沉默不算"无回应"） | 连续两章以上，主角被攻击后无任何回应 |

**最低标准**（跨题材通用）：Ch3结束前至少出现一个对主角产生压力/攻击/威胁的外部人物。这个人物不需要是大反派——可以是挑衅的同事、质问的上司、落井下石的亲戚。

**为什么会误判**：作者常以为"主角内心很痛苦=冲突已经建立了"。但网文读者的情绪代入需要外部靶心——读者需要一个"我在等着看她怎么反击这个人"的具体对象。

## 三、追读期待感三问（P1级）

Ch3结束时，读者必须能回答以下三个问题。如果两个以上答案为"不知道"，判为期待感缺失。

| 问题 | 判断标准 | 红灯 |
| --- | --- | --- |
| **① 明天看什么？** | 读者是否能指认一个具体的"明天的章节我会看到什么" | 答案模糊——"看她慢慢好起来""看她一个人打拼" |
| **② 等谁被打脸？** | 读者是否能指认一个具体的"我等着看这个人被打脸/后悔"的对象 | 没有明确的反派靶心 |
| **③ 凭什么能赢？** | 读者是否能指认女主的一个具体能力/资源/秘密武器——且这个能力已在正文中以可感知的方式展示过 | 能力只以标签出现（"她是天才谈判顾问"），从未在正文中展示过能力的可感知维度 |

**经典红灯**："她会好起来的"——这不是网文的期待，是现实生活的逻辑。网文需要的是"她下周回归行业峰会那天，他会看到她坐在主讲台上"。

## 四、支线展开能力评估（P2级，但影响签约判断）

Ch5结束时，统计当前可展开的支线数：

| 支线类型 | 说明 |
| --- | --- |
| 复仇/打脸线 | 渣男后悔/反派被扳倒/背叛者被曝光 |
| 事业崛起线 | 主角回归职场/开启新事业/展示隐藏能力 |
| 身世/秘密线 | 主角的隐藏身份/未揭示的过去/被掩盖的真相 |
| 关系线 | 新感情/旧情复燃/对手变成盟友 |
| 家族/势力线 | 家族恩怨/势力博弈/幕后黑手 |

**最低标准**（300万字长篇）：Ch5结束时≥3条可展开支线。若只有1-2条，说明设定层面的冲突网格太稀疏，不足以支撑长篇连载。

## 五、使用方式

- 审阅Ch1-3时，本文件作为 `章节正文审阅检查清单.md` 的补充——后者管单章质量，本文件管Ch1-3的整体架构质量
- 命中红灯项时，问题等级按上述标注（P0/P1/P2）
- 不得用"文笔好""人设新颖"等单项亮点冲淡架构级红灯
