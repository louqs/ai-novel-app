# Human Story Writer - 人味短篇小说创作

创作像真人写的中文短篇小说，拒绝AI味。

## 核心原则：像人，不像模板

**AI写作的典型问题：**
- 开头总喜欢"在...的世界里"或"阳光洒在..."
- 结尾强行升华、点题、总结人生哲理
- 人物性格扁平，行为逻辑模板化
- 对话像教科书，缺乏口语感和个性
- 情感描写空泛，堆砌形容词
- 过度使用排比、对仗、三段式
- 每段长度相近，结构太工整
- 破折号、省略号滥用
- 结尾喜欢用"原来..."、"那一刻，他终于明白了..."

**人写作的特点：**
- 开头可能突然、随意，像从中间切入
- 结尾可能开放、模糊、不圆满
- 人物有矛盾、有缺陷、有不可预测性
- 对话有口语、有打断、有言外之意
- 情感通过细节和行为呈现，而非直说
- 句子长短不一，节奏自然
- 有废话、有留白、有不完美
- 有作者的个人视角和偏见

## 创作流程

### 1. 确定故事核心（30秒思考）

回答三个问题：
- 这故事讲什么？（一句话）
- 主角想要什么？
- 什么阻止他得到？

**不要：**
- 构思过于宏大的主题
- 设计过于复杂的人物关系
- 预设道德教训或人生感悟

### 2. 开头：直接切入

**好的开头范例：**
```
老李第三次把烟头按灭在窗台上的时候，楼下的车终于走了。
```
```
"你又来了。"她说，没抬头。
```
```
钱不够。还差三百。
```

**避免的开头：**
```
在繁华的都市里，有一个孤独的灵魂...（太抽象）
夕阳西下，金色的阳光洒在...（太文艺）
人生就像一场旅行...（太说教）
```

### 3. 中段：细节驱动

用具体细节推进故事，而非抽象描述。

**不好：** 他很伤心，感到无比痛苦。
**好：** 他盯着那张汇款单看了很久，直到收款人姓名变得模糊。

**不好：** 她是一个温柔善良的人，总是帮助别人。
**好：** 楼下流浪猫的碗里，每天早上都有新猫粮。她说是顺手买的。

### 4. 对话：口语化、有潜台词

**不好：**
```
"我觉得我们应该好好谈谈这个问题，因为它关系到我们的未来。"
"是的，我完全同意你的观点，我们应该共同面对。"
```

**好：**
```
"你最近怎么了？"
"没怎么。"
"又没怎么。"
她把碗重重放下。"那你想听什么？"
```

### 5. 结尾：克制升华

**不要：**
- 总结全篇主题
- 强行给出人生感悟
- 用"原来..."句式
- 让所有问题得到解决

**可以：**
- 开放式结尾
- 留下疑问
- 戛然而止
- 一个小细节收束

**好的结尾范例：**
```
他走进地铁站，没回头。她也没追。
```
```
老李想，明天该去买烟了。
```
```
灯灭了。有人在黑暗里叹了口气。
```

## 语言细节清单

### 句式变化

- 长短句交替，避免都是中等长度
- 偶尔用短句制造冲击力
- 允许句子不完整（口语感）
- 避免每个句子都很"完整"和"工整"

### 词汇选择

- 少用书面语：摒弃、亦、乃至、所谓
- 多用口语：算了、罢了、也是、就说
- 具体词代替抽象词：用"烟灰缸满了"代替"时间流逝"
- 动词优先于形容词

### 标点使用

- 少用破折号（——）
- 少用省略号（......）
- 多用句号，让句子更短
- 对话可以没有引号，用分行表示

### 段落节奏

- 长短段落交替
- 偶尔单句成段
- 避免每段都是3-5句

## 人物塑造

### 不要做

- 给人物贴标签（善良、勇敢、聪明）
- 人物行为完全符合其"设定"
- 让人物说出自己的人设
- 所有人物说话方式相同

### 要做

- 让人物有矛盾（嘴硬心软、表面洒脱内心纠结）
- 让人物有缺点（小气、八卦、懒惰、虚伪）
- 让人物行为有意外（好人做坏事，坏人动恻隐）
- 每个人有独特的说话方式

## 场景描写

**不好（堆砌形容词）：**
```
破旧的房间里弥漫着陈旧的气息，昏暗的灯光下，斑驳的墙壁诉说着岁月的沧桑。
```

**好（具体细节）：**
```
房间里的灯泡瓦数太小，墙皮起鼓，像要掉不掉的样子。
```

## 情感表达

**不好（直白说出）：**
```
他感到一阵莫名的悲伤，内心涌起一股难以言喻的孤独。
```

**好（通过行为暗示）：**
```
他点了支烟，没抽，就让它烧着。烟灰掉在裤子上，他也没管。
```

## 故事结构参考

### 短篇常见结构

1. **切片式**：截取生活一个片段，无明确起止
2. **转折式**：开头铺垫，中间转折，结尾回望
3. **对比式**：两个时间点或两种状态对比
4. **渐进式**：从小事开始，逐渐揭示核心

### 字数参考

- 微型小说：500-1500字
- 短篇小说：1500-5000字
- 中篇小说：5000-20000字

## 检查清单

写完后自检：

- [ ] 开头是否直接切入？
- [ ] 结尾是否克制，没有强行升华？
- [ ] 对话是否口语化？
- [ ] 是否用细节代替了抽象描述？
- [ ] 句子长短是否有变化？
- [ ] 是否有人物矛盾和缺陷？
- [ ] 是否避免了三段式排比？
- [ ] 是否减少了破折号和省略号？
- [ ] 情感是否通过行为呈现？
- [ ] 读起来是否像人写的？

## 示例对比

### AI味重

```
在这个繁华喧嚣的城市里，有一个孤独的身影。他每天穿梭在人群中，却感到无比寂寞。夕阳西下，金色的阳光洒在他身上，那一刻，他终于明白：真正的孤独，不是没有人陪伴，而是失去了爱的勇气。

岁月如流水般逝去，带走了他的青春，却带不走心中的伤痕。原来，人生就是一场孤独的旅程，每个人都是自己故事里的主角。
```

### 人味重

```
老王站在天台上抽烟。

风挺大，烟灰还没掉就被吹跑了。楼下有人在喊什么，听不清。他也不在乎。

手机震了一下。老婆发的："回来吃饭吗？"

他看了很久，没回。把烟头弹下去，看着它变成一个小点，消失。

转身上楼。"回。"
```

## 最后提醒

1. **少即是多**：删掉所有可以删的字
2. **具体胜过抽象**：用细节说话
3. **矛盾产生真实**：人物要有缺陷
4. **不完美才是人**：留白、突兀、不圆满
5. **写给读者看，不是写给AI检测器看**：自然最重要

---

记住：好的短篇小说是让读者忘了有人在写，而不是让读者惊叹"写得多好啊"。
