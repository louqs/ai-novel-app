# 三卷万能骨架模板

> **来源**：自知乎精华《如何写好一个优质的长篇小说？》（摘星，2026-06-17）。此模板适用于所有题材的通用三卷结构，可作为总纲设计的起点骨架，再按题材特性叠加具体模板。
>
> **定位**：本模板是"最小通用骨架"——不替代 `通用skills/写作研究/起点模板/总纲模板/` 下的题材专属模板，而是在选定主模板前或不确定主模板时，确保总纲具备最基本的节奏框架。一旦选定了题材专属主模板，以主模板为准，本骨架退为结构参照。

## 三卷比例分配

| 卷位 | 篇幅占比 | 核心任务 | 关键检查点 |
| --- | --- | --- | --- |
| **第一卷（开局）** | **25%** | 交代主角处境 → 触发转折事件 → 确立核心目标 → 第一次受挫/成长 | ✅ 前3章"冲突起手→应对失败→更深层冲突"递进 |
| | | | ✅ 章末明确续读钩子 |
| | | | ✅ 前25%内读者清楚"主角要什么、阻碍是什么" |
| **第二卷（中盘）** | **50%** | 多线并行推进 → 冲突全面升级 → 重大反转/心碎低谷 → 主角彻底蜕变 | ✅ 无连续4章以上的"纯推进"段 |
| | | | ✅ 反转/低谷事件足够摧毁读者预期 |
| | | | ✅ 主角蜕变有具体的代价付出 |
| **第三卷（终局）** | **25%** | 回收主线伏笔 → 终极对决 → 所有人物的归宿交代 → 主题完成闭环 | ✅ 短线伏笔已在本卷前回收或入收尾链 |
| | | | ✅ 大结局不依赖末章首次新信息 |
| | | | ✅ 配角（含反派）有独立归宿 |

> **等比缩放说明**：若全书规划为4卷或5卷，按"开局群≈25%、中盘群≈50%、终局群≈25%"的比例分配卷数，而不是生硬套三个物理卷。例如6卷书 → 第1-2卷为开局群、第3-5卷为中盘群、第6卷为终局群。

## 各卷的通用节奏模板

### 第一卷（开局25%）· 基本节奏

```text
第1-3章（黄金三章）：冲突/异常起手 → 主角应对并碰壁 → 更深层问题暴露
第4-8章（身份确立）：主角逐步了解世界规则/势力格局 → 确立阶段性目标 → 收获第一个小同盟或小资源
第9-12章（第一次重大挫折）：第一次针对核心目标的尝试以失败告终 → 代价付出 → 留下"原来没这么简单"的认知
第13章至卷尾（新方向）：挫折后获得新信息/新能力/新盟友 → 重新锁定方向 → 卷末钩子指向中盘更大冲突
```

### 第二卷（中盘50%）· 基本节奏

```text
卷首（约10%）：承接第一卷的尾巴 → 展开新地图/新势力/新矛盾 → 节奏加速
卷中（约30%）：多线并行 → 冲突持续升级 → 每5-8章安排一次中刺激点（反转/关系突破/关键信息揭示）
卷中后段（约10%）：重大反转/心碎低谷 → 读者预期被摧毁 → 主角信念受最大考验
卷尾（约10%）：主角做出关键选择/彻底蜕变 → 新能力或新认知觉醒 → 卷末钩子指向终局
```

### 第三卷（终局25%）· 基本节奏

```text
卷首（约5%）：最终局势确立 → 各方势力就位 → 最后一块拼图揭示
卷中（约15%）：终局对决/终极冲突 → 伏笔密集回收 → 代价全面兑现
卷尾（约5%）：尘埃落定 → 所有人物的归宿 → 主题句/余韵
```

## 核心三要素前置确认

在开始分卷设计前，必须先钉死以下三个问题——它们决定了三卷骨架能否对准同一本书：

```text
主题（内核）：这本书最终想表达什么？不是题材，是内核
总冲突（驱动力）：外部恩怨/危机 + 主角内心缺陷/执念
终极目标（终点）：主角从头到尾要完成的事——全程不跑偏
```

若三个问题中任何一个的回答是模糊的，三卷骨架会形同虚设——因为不知道"第一卷的转折该转向哪里"。

## 与现有总纲模板的关系

- **优先选题材专属模板**：本骨架是最低通用保底方案。如果已通过 `通用skills/写作研究/起点模板/总纲模板/` 选定了主模板，以主模板为准。
- **本骨架的适用场景**：
  - 项目定位尚未明确到能选主模板（还看不清主承诺）
  - 需要快速搭建一个可执行的三卷框架，后续再细化
  - 作为总纲设计初稿的检查基准——检查现有总纲是否偏离了基本的3:5:2比例
- **主模板选定后**：将本骨架中的卷级关键节点与主模板的核心字段合并，以主模板为准，本骨架退为结构参照。
