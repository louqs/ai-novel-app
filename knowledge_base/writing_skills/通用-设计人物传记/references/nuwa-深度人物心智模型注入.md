# Nuwa 深度人物心智模型注入

> 源自 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 的思维框架提炼方法论，经虚构人物设计适配后注入人物传记工具体系。核心理念：一个好的人物不是漂亮人设的堆砌，而是一套**可运行的认知操作系统**。

---

## 一、核心区分：人物不是标签，是认知操作系统

业余人物设计止步于"姓名 + 外貌 + 性格标签"。Nuwa 级人物设计要求回答以下五层：

| 层 | 问题 | 对应传记字段 |
| --- | --- | --- |
| **心智模型** | 他用什么镜片看世界？ | 世界观 / 价值观 / 误信 |
| **决策启发式** | 他做判断时遵循什么快速规则？ | 动机 / 边界 / 底线开关 |
| **表达DNA** | 他怎么说话、怎么不说话？ | 语言指纹 / 写作抓手 |
| **矛盾与张力** | 他内在有什么冲突？ | 缺陷 / 执念 / 秘密 / 心理弧线 |
| **诚实边界** | 他看不到什么、做不到什么？ | 能力边界 / 盲区 |

**关键区分**：设计的不是"他是什么样的人"（静态标签），而是"他**怎么**看世界、**怎么**做决定、**怎么**表达"（可运行系统）。

---

## 二、心智模型提炼：三重验证（虚构人物适配版）

### 2.1 什么是人物的心智模型

心智模型 = 人物看待世界的核心镜片，决定他如何理解事件、判断他人、做出选择。

**不是**：

- "他很聪明"（这是标签）
- "他相信努力就会有回报"（这是信念，但太泛）

**而是**：

- "信任是需要挣的，不是给的" → 他在所有关系中都会先设防、先测试
- "规则是为了被利用的，不是被遵守的" → 他在任何体制中都会先找漏洞
- "人不会变，只会藏" → 他对任何人的改变都持怀疑态度，导致关键误判

### 2.2 三重验证（虚构适配版）

一个候选观点要被认定为"心智模型"而非"随口台词"，必须通过三重验证：

#### 验证1：跨场景复现

同一个心智模型在**至少2个不同类型的场景**中主导人物的判断或行动。

例：人物的心智模型是"欠了人情就必须还"——

- 场景A（日常）：同事帮他挡了一次领导的问责，他当晚就去找机会还回去，睡不着
- 场景B（危机）：反派救了他一命，他在关键选择上犹豫了——即使反派在做错事
- 场景C（亲密）：伴侣对他好，他反而有压力，觉得"还不清"

→ 跨3个场景复现 → 这是真正的心智模型，不是单场台词

**反例**：人物只在某一场合说了句"这世界不公平"，但其他场景中他的行为并不体现这种 cynical 判断 → 这只是场景台词，不是心智模型

#### 验证2：有生成力

用这个心智模型可以**推断人物对新情境的可能反应**。

例：人物心智模型是"权力只认实力，不认道理"——

- 面对新上司 → 他不会先讲道理，会先展示实力或收集把柄
- 面对弱势者的求助 → 他会先判断"帮你对我有什么好处/风险"
- 面对规则变化 → 他会先判断"谁受益、谁受损"，而不是"规则公不公平"

→ 能生成新推断 → 这是真正的心智模型。作者可以用它来判断人物在任何新场景中的默认反应。

#### 验证3：有排他性

不是所有角色都会这样想。这个心智模型体现了**这个人物的独特视角**，能把他和故事中其他人物区分开。

例：同样面对"被朋友背叛"——

- 人物A（心智模型"人不会变，只会藏"）：我早该看出来的，以后再也不信任何人
- 人物B（心智模型"每个人都有苦衷"）：他一定有难处，我要去问清楚
- 人物C（心智模型"背叛是弱者的武器"）：是我让他有了背叛的机会，是我还不够强

→ 三个人物的心智模型不同 → 同样的触发事件产生完全不同的后续行动 → 故事分叉

### 2.3 心智模型的数量与分层

- **核心人物**：3–5个心智模型，至少1个是"误解型"（最终会被修正的误信）
- **重要人物**：2–3个心智模型
- **次要人物**：1–2个心智模型，其中至少1个是能与主角心智模型形成对照的

**降级规则**：

- 只通过1–2重验证 → 降级为"决策启发式"（见第三节）
- 0重都没过 → 只是台词，不纳入人物裁判源

### 2.4 心智模型的记录格式

每个人物传记中，心智模型应按以下格式记录：

```markdown
### 心智模型1：[名称，一句话概括]

**一句话**：[最简描述，最好用人物自己的口吻]

**跨场景证据（≥2个不同场景类型）**：
- 场景类型A：[具体行为/判断] —— 对应第X卷第Y章
- 场景类型B：[具体行为/判断] —— 对应第X卷第Y章

**生成力验证**：如果遇到[新情境类型]，此人物默认会[推断反应]

**排他性验证**：故事中[另一个人物名]面对同样情境会[不同反应]，因为ta的模型是[XXX]

**适用边界**：这个模型在[什么情况下]会失效或让他犯错

**弧线关联**：这个模型在心理弧线的[第N步]会被[击穿/修正/强化]
```

## 三、决策启发式：人物的快速判断规则

### 3.1 什么是决策启发式

决策启发式 = 人物在压力下快速做出判断的"如果X，则Y"式规则。它们比心智模型更具体、更行动导向。

**与心智模型的关系**：心智模型是"世界观镜片"，决策启发式是"镜片下的快速反应规则"。一个心智模型通常会产生多条决策启发式。

例：心智模型"信任是需要挣的，不是给的" →

- 启发式1："如果对方主动示好，先反问自己：他想要什么"
- 启发式2："如果对方拒绝透露任何个人信息，立即停止信息交换"
- 启发式3："如果对方连续三次言行一致，开始考虑信任"
- 启发式4："如果对方在压力下仍然守住了底线，可以给一次机会"

### 3.2 决策启发式的要求

- 每条必须有具体案例支撑（来自正文或大纲中的至少一个情节节点）
- 可以被新情境触发（不只适用于原始案例）
- 核心人物5–10条，重要人物3–5条，次要人物1–3条
- 至少1条启发式是"错误规则"——会在关键时刻导致人物做出错误判断

### 3.3 决策启发式的记录格式

```markdown
### 决策启发式

1. **[规则名]**：如果[触发条件]，则[默认反应]
   - 应用场景：[什么时候用]
   - 案例支撑：[具体情节节点]
   - 风险：[这条规则在什么情况下会让他犯错]

2. **[规则名]**：...
```

## 四、表达DNA：人物的语言指纹体系

### 4.1 表达DNA的量化维度

Nuwa 级别的表达DNA不只是"说话很冷"或"爱怼人"，而是从以下可测量维度建立人物的语言身份证：

| 维度 | 测量/描述方式 | 传记字段映射 |
| --- | --- | --- |
| **平均句长** | 短句型（5–15字）/ 中等（15–30字）/ 长句型（30+字） | 语言指纹 |
| **疑问句比例** | 爱反问 / 爱设问 / 很少提问 / 用陈述伪装疑问 | 语言指纹 |
| **类比密度** | 高频类比 / 偶尔类比 / 几乎不用类比 | 语言指纹 |
| **第一人称使用率** | "我"高频 / "我"低频（自我隐藏） / 用"你"或"我们"替代 | 语言指纹 |
| **确定性语气** | "一定/显然/绝对"型 / "也许/可能/大概"型 / 混合型 | 语言指纹 |
| **转折频率** | 高频转折（"但是/然而/不过"） / 直线推进 / 先让步后转折 | 语言指纹 |
| **引用习惯** | 引经据典 / 引用数据 / 引用他人话 / 从不引用 | 语言指纹 |

### 4.2 风格标签（二元光谱）

每个人物在以下光谱上应有明确位置：

```text
正式 ←————————→ 口语
抽象 ←————————→ 具体
谨慎 ←————————→ 断言
学术 ←————————→ 通俗
长句 ←————————→ 短句
铺垫型 ←————————→ 结论先行
数据驱动 ←————————→ 叙事驱动
攻击型 ←————————→ 退缩型
```

### 4.3 禁忌词与口癖

- **禁忌词**：这个人物**绝不说**的词或句式（例如：一个硬汉角色绝不说"人家""好难过""呜呜"）
- **高频口癖**：人物反复使用的词/句式（适度使用，过多反而变成标签化模仿秀）
- **情绪变体**：同一人物在愤怒/恐惧/伪装/亲密时的句长、停顿、回避方式应有规律性变化

### 4.4 声口分众（对不同的说话对象）

核心人物默认补出声口分众表：

| 说话对象 | 句式变化 | 用词变化 | 态度变化 |
| --- | --- | --- | --- |
| 上位者 | | | |
| 同级/搭档 | | | |
| 下属/弱者 | | | |
| 亲密对象 | | | |
| 敌对对象 | | | |

### 4.5 表达DNA的记录格式

```markdown
### 语言指纹（Nuwa 表达DNA）

**句长偏好**：[短/中/长] —— [具体描述]
**疑问句用法**：[爱反问/爱设问/少问/陈述伪装疑问] —— [具体描述]
**类比习惯**：[高频/偶尔/几乎不] —— [典型类比类型]
**确定性表达**：[断言型/犹豫型/混合型] —— [具体描述]
**转折方式**：[高频转折/直线推进/先让后转] —— [具体描述]
```

## 五、矛盾处理深度框架

### 5.1 矛盾是人格深度，不是Bug

Nuwa 的核心原则：**矛盾是人物的核心特征，不是需要修复的缺陷**。一个人物没有内在矛盾 = 纸板人。

### 5.2 三种矛盾类型

#### 类型1：时间性矛盾（人物弧线的引擎）

人物的观点/行为随故事推进发生变化。这是**心理弧线的本质**。

- 早期相信A → 后来经历事件 → 开始怀疑 → 最终接受B
- 处理方式：在传记中明确标注"早期观点"vs"后期观点"，把变化节点写入心理弧线
- **关键**：变化必须有触发事件，不能凭空"成长了"

例：范闲——从"精致的利己主义者"到"责任的承担者"，每次变化都有具体事件触发

#### 类型2：领域性矛盾（人物复杂度的来源）

人物在不同领域/关系中表现出不同的行为准则。这不叫"人设崩了"，这叫"人有多个维度"。

- 在工作中冷酷无情 → 对家人温柔妥协
- 对敌人毫不手软 → 对无辜者极度克制
- 处理方式：分领域记录，不强求统一。这正是深度的来源。

**检查**：如果一个人物在所有场景中的反应都可以被一个标签概括（"他就是个狠人"），说明缺乏领域性矛盾 → 人物扁平。

#### 类型3：本质性张力（人物最有魅力的部分）

人物内在的价值观冲突，两种力量在心里持续打架。

- 既渴望自由又渴望安全感
- 既想复仇又知道复仇会毁了自己
- 既相信规则又忍不住想打破规则
- 既想亲近人又怕被人看穿

**处理方式**：明确记录为"核心张力"，并写清这个张力在什么情境下会被触发、在什么选择中会达到顶峰。

### 5.3 错误的矛盾处理方式

- ❌ 选一边忽略另一边（把多面人变成单面人）
- ❌ 编一个调和解释来抹平矛盾（"其实他本质上还是……"）
- ❌ 假装矛盾不存在（让对立的行为从不发生在同一场景）
- ✅ 保留矛盾，让它在关键选择中爆发

### 5.4 矛盾与心理弧线的对接

每个人物传记中，至少**一对本质性张力**要写入心理弧线的关键步骤：

- 弧线早期：人物用其中一面的逻辑主导行为
- 弧线中期：另一面开始发出声音，产生内耗
- 弧线高潮：两股力量在关键选择中正面相撞
- 弧线收束：人物做出了选择，但代价清楚（未必是"选对了"）

### 5.5 矛盾的记录格式

```markdown
### 内在矛盾与张力

**核心张力1**：[A] vs [B]
- A的表现场景：
- B的表现场景：
- 碰撞节点：[弧线第N步，具体事件]
- 碰撞结果：[失去/获得/被击穿了什么]

**时间性矛盾（观点演化）**：
- 早期：[阶段/卷] —— 相信/行为：[XXX]
- 转折事件：[具体事件]
- 后期：[阶段/卷] —— 相信/行为：[XXX]
```

## 六、诚实边界：人物的认知盲区

### 6.1 为什么需要诚实边界

一个"什么都能看透、什么都能做到"的人物 = 不可信的人物。每个人物都应该有**认知盲区**——他们看不到的东西、理解不了的事情、做不到的选择。

### 6.2 诚实边界的类型

| 类型 | 描述 | 示例 |
| --- | --- | --- |
| **经验盲区** | 因为缺乏某种经历而无法理解某类人/事 | 没穷过的人理解不了"省那一块钱"的执念 |
| **价值观盲区** | 因为某种核心信念而系统性低估/忽视某些信息 | 相信人性本善的人看不出对方在利用自己 |
| **能力盲区** | 什么情境下这个人物的能力会失效 | 逻辑高手在处理纯情感问题时的笨拙 |
| **信息盲区** | 人物不知道但读者/作者知道的事 | 不知道自己的导师才是真正的敌人 |
| **性格盲区** | 性格特质在特定情境下变成弱点 | 谨慎变成了犹豫不决，果断变成了鲁莽 |

### 6.3 诚实边界的用法

- 诚实边界不是装饰，而是**情节的发动机**：人物的盲区 = 他会在哪里跌倒
- 核心人物至少写3条诚实边界，其中至少1条与主线情节直接相关
- 重要人物至少写1条会直接影响其剧情功能的诚实边界
- 诚实边界必须在正文中被触发过（或计划触发），不能只写在传记里

### 6.4 诚实边界的记录格式

```markdown
### 诚实边界（认知盲区与能力边界）

1. **[盲区类型]**：[具体描述]
   - 来源：[为什么有这条盲区——经历/价值观/性格]
   - 正文触发：[在哪一章/哪卷会被触发]
   - 后果：[触发后会怎样——误判/失去/受伤]
```

## 七、智识谱系：人物的思想血缘

### 7.1 什么是人物的智识谱系

一个人的思维方式不是凭空产生的——他受谁影响（思想来源），他又影响了谁（思想传承）。这构成了人物的"思想血缘"。

对于虚构人物，智识谱系回答：

- 他现在的思维框架是从哪里来的？（导师、经历、阅读、创伤）
- 他的思维方式正在影响谁？（徒弟、追随者、被保护者、对手）
- 他在故事的思想地图上处于什么位置？（他的立场与其他人物立场的对比关系）

### 7.2 智识谱系的记录格式

```markdown
### 智识谱系

**影响过我的人/事**：
- [人物/事件] → 我学到了/形成了 [具体心智模型/信念]
- [人物/事件] → 我学到了/形成了 [具体心智模型/信念]

**我正在影响的人**：
- [人物名] → 我正在传递给ta的是 [具体心智模型/信念]
- [人物名] → 我正在传递给ta的是 [具体心智模型/信念]

**我在思想地图上的位置**：
- 与[人物A]的分歧点是：
- 与[人物B]的共鸣点是：
- 我代表故事中的[哪种立场/价值观/方法论]
```

## 八、Nuwa 注入后的质量自检清单

设计完成后，用以下问题自检人物是否已具备 Nuwa 级深度：

### 心智模型

- [ ] 核心/重要人物有 2–5 个心智模型，每个有 ≥2 个不同场景类型的证据？
- [ ] 每个心智模型都有明确的适用边界和失效条件？
- [ ] 不同人物的心智模型之间有差异性，能产生碰撞？
- [ ] 至少 1 个心智模型是"误解型"，会在弧线中被修正？

### 决策启发式

- [ ] 核心人物有 5–10 条"如果X则Y"式规则？
- [ ] 至少 1 条是"错误规则"，会在关键时刻导致误判？
- [ ] 每条都有具体案例支撑？

### 表达DNA

- [ ] 遮住名字读 100 字对话/独白，能认出是谁？
- [ ] 有声口分众表（对不同人说话方式不同）？
- [ ] 有禁忌词和情绪变体？
- [ ] 不是通用AI味，也不是过度模仿变成 caricature？

### 矛盾与张力

- [ ] 至少有 1 对本质性张力（价值观内在冲突）？
- [ ] 至少有 1 处领域性矛盾（不同场景不同行为准则）？
- [ ] 时间性矛盾已写入心理弧线？

### 诚实边界

- [ ] 核心人物至少 3 条诚实边界，其中 1 条与主线直接相关？
