# 正文可调用素材清单：从人物传记到正文落地的执行层桥接

> 本文件解决"人物传记写得很满，但正文里人物还是没立住"的核心问题。它不是另一份"人物设定"，而是把传记中的抽象特质翻译成**正文可直接插入的具体片段**。

---

## 一、问题诊断：为什么传记丰满、正文扁平？

常见断层模式：

| 传记里有 | 正文里只有 | 缺失了什么 |
| --- | --- | --- |
| "心智模型：信任是需要挣的，不是给的" | 主角正常交谈 | 没有把"先设防、先测试"写成具体的审问节奏、肢体距离、话不说完 |
| "决策启发式：如果对方主动示好，先反问自己：他想要什么" | 两人对话推进了情节 | 没有在对话中插入人物内心的判断句、延迟回应、岔开话题等具体行为 |
| "表达DNA：短句型，断言语气，禁忌词包括'可能''也许'" | 对话里用了"可能吧""也许可以" | 声口崩了，但没人发现 |
| "诚实边界：无法理解纯情感驱动的行为" | 朋友哭诉，主角安慰得很到位 | 盲区没有触发，人物过于万能 |

**根因**：传记是"裁判源"（作者用来核查"这样写对不对"），但正文写作需要的是"施工清单"（AI/作者用来直接插入"这次就这样写"）。

---

## 二、正文可调用素材清单：四种可直接插入的片段类型

每种人物传记设计完成后，默认在传记末尾追加以下四种素材类型。它们的格式设计原则是：**正文创作者（AI或人类）拿到后不需要再理解、再翻译，可以直接贴进正文或稍作场景适配即可使用**。

### 2.1 压力反应微镜头（≥5 个 / 核心人物）

**定义**：人物在特定压力类型下的 80–150 字微型片段。不是"他紧张时会搓手"这种抽象描述，而是可直接插入正文的完整动作+身体反应+内心判断。

**格式**：

```markdown
### 压力反应微镜头

**压力类型：被当众质疑能力**
> [80-150字微镜头，含外部动作 → 身体反应 → 内心一闪]

**压力类型：发现被信任的人隐瞒了关键信息**
> [80-150字微镜头]

**压力类型：必须在两害之间做出选择**
> [80-150字微镜头]

**压力类型：被迫向讨厌的人求助**
> [80-150字微镜头]

**压力类型：独处时的真实状态（无观众时的破防时刻）**
> [80-150字微镜头]
```

**设计规则**：

- 每个微镜头必须直接体现至少 1 个心智模型和 1 条决策启发式
- 不能写成"他会怎么怎么样"的说明文；必须用第三人称现在时写成可直接插入正文的叙事片段
- 微镜头不是"正确答案"——正文不一定原样贴入，但它提供了人物的**默认反应基线**，写手可以以此为锚点做场景适配

### 2.2 声口即时贴（≥10 句 / 核心人物）

**定义**：人物在不同情境下的标志性台词，每句 10–40 字。不是"口头禅：他说'有意思'"这种标签，而是按情境分类、可直接复制或用微小场景适配后贴入正文的完整对话片段。

**格式**：

```markdown
### 声口即时贴

**面对挑衅**：
> "你说完了？那轮到我了。"（短句，断言，不反问）
> "我要是你，就不会把这句话说完。"

**面对求助**：
> "帮你可以。但你要先告诉我，为什么是你来开口。"
> "这件事对我有什么好处？——别跟我说'因为是朋友'。"

**面对夸奖**：
> "运气。"（移开视线，不接话）
> "没用的事少说。"

**面对背叛/失望**：
> "我本以为你至少会等到更好的时机。"
> （不说话，把东西放下，转身走——这是更重的一句）

**在亲密关系中破防的瞬间**：
> "你别这样看我。"（第一人称罕见地出现）
> "……算了。"（放弃争辩的信号，比任何长篇大论都重）
```

**设计规则**：

- 每句必须能从表达DNA中可追溯（句长、确定性语气、禁忌词检查）
- 不能写成人物的"金句集锦"——必须有情境标签，让写手知道"什么时候用"
- 必须包含至少 2 句"没说出口但身体语言在说"的情况（沉默、动作替代语言）

### 2.3 误判预设场景（≥3 个 / 核心人物）

**定义**：人物因为某个心智模型或诚实边界，在特定情境下**必然会做出错误判断**的微型场景描述。这是人物缺陷（缺陷="会在关键时刻反噬的心理/行为弱点"）从传记概念到正文落地的关键桥接。

**格式**：

```markdown
### 误判预设场景

**误判类型：因为"信任是需要挣的"而过早排除真正的盟友**
- 触发情境：[具体场景描述]
- 人物的错误判断：[他认为……但实际上……]
- 会导致的后果：[具体可写的连锁反应]
- 这个误判适合出现在：第X卷/约第Y章前后

**误判类型：因为"人不会变，只会藏"而错过对方的真实改变**
- 触发情境：[具体场景描述]
- 人物的错误判断：[他认为……但实际上……]
- 会导致的后果：[具体可写的连锁反应]
- 这个误判适合出现在：第X卷/约第Y章前后
```

**设计规则**：

- 每个误判必须直接来自诚实边界中的一条
- 必须写清"人物为什么会这样判断"（从心智模型推导）+ "实际上发生了什么"（读者/作者知道的真相）
- 必须有明确的卷/章定位建议，不能只是一个抽象概念

### 2.4 关系拉扯动作库（≥8 组 / 核心人物）

**定义**：人物与每个关键关系对象之间的"标志性互动模式"——不是"他们是朋友"这种静态标签，而是"他们在一起时，必然会发生什么类型的拉扯"。

**格式**：

```markdown
### 关系拉扯动作库

**与[角色A]——权力博弈型拉扯**
- 标志性互动1：[具体可写的场景动作描述，80-150字]
- 标志性互动2：[具体可写的场景动作描述]
- 每次互动的底层动力：[谁在争什么/谁在躲什么]
- 这种拉扯在什么情况下会翻面：[具体触发条件]

**与[角色B]——信任试探型拉扯**
- 标志性互动1：[具体可写的场景动作描述]
- 每次互动的底层动力：[……]
```

**设计规则**：

- 每组至少 2 个标志性互动，且必须体现双方心智模型的碰撞
- 必须写清"底层动力"——不是表面在争什么，而是各自的心智模型在碰撞什么
- 必须写清"翻面条件"——这种拉扯模式在什么情况下会彻底改变

## 三、正文调用清单与传记其他字段的关系

| 传记字段 | 正文调用清单如何从中提取 |
| --- | --- |
| 心智模型 | → 提取为每个心智模型生成 1 个压力反应微镜头 + 1 个误判预设场景 |
| 决策启发式 | → 提取为声口即时贴中的"判断句"和"选择句" |
| 表达DNA | → 翻译为声口即时贴的句长、语气、禁忌词约束 |
| 诚实边界 | → 翻译为误判预设场景的触发源 |
| 关系网 | → 翻译为关系拉扯动作库 |
| 矛盾与张力 | → 翻译为压力反应微镜头中"两个声音在打架"的内心片段 |

**关键转换原则**：传记是"裁判语言"（用来核查对不对），正文调用清单是"施工语言"（用来直接写）。两者必须共存于一份传记中，但职责完全不同。

## 四、正文调用清单的使用流程

### 4.1 在生成章节控制卡时

生成控制卡时，必须从出场人物的正文调用清单中提取本章要用的具体素材：

- 本章人物的压力类型是什么？→ 从压力反应微镜头中选取匹配的 1-2 个，写入场景单元的"人物状态变化"
- 本章人物的关键对话是什么？→ 从声口即时贴中选取匹配情境的 2-3 句，写入场景单元的"对话链"
- 本章是否需要触发人物误判？→ 从误判预设场景中检查是否有匹配本章情境的预设，若有，写入控制卡的"中段回报"或"章末钩子"

### 4.2 在写正文时

- 开场人物出场 → 先查压力反应微镜头，找到当前情境的默认反应基线
- 人物说话 → 先查声口即时贴，确认语气/句长/禁忌词
- 人物做选择 → 先查决策启发式，确认默认判断规则（以及这次是否要违反它）
- 关键对话 → 先查关系拉扯动作库，确认双方互动的底层动力

### 4.3 在审阅正文时

- 查人物声口：对比声口即时贴中的句长/语气/禁忌词，正文中的对话是否符合？
- 查人物反应：正文中的压力反应是否与压力反应微镜头中的默认基线一致（或如有偏离，是否有情节理由）？
- 查人物误判：如果传记设定了误判预设场景，正文中是否在对应位置触发了？
- 查关系拉扯：正文中的关键关系互动是否体现了关系拉扯动作库中的底层动力？

---

## 五、最低交付标准

核心人物的传记完成后，正文可调用素材清单必须至少包含：

- [ ] 5 个压力反应微镜头（覆盖 ≥3 种不同的压力类型）
- [ ] 10 句声口即时贴（覆盖 ≥4 种不同的情境类型，含 ≥2 句"沉默/动作替代语言"）
- [ ] 3 个误判预设场景（每个来自不同的诚实边界，每个有明确的卷/章定位建议）
- [ ] 与每个关键关系对象至少 2 组标志性互动（含底层动力和翻面条件）

重要人物至少包含核心人物的 60%（3 个微镜头、6 句声口、2 个误判预设、1 组关键关系拉扯）。
