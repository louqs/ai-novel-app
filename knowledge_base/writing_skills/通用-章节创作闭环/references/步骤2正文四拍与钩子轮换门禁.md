# 步骤 2 正文四拍与钩子轮换门禁

> 适用位置：`通用-章节创作闭环` 的步骤 2（`通用-创建小说正文`）执行后立即复核。

## 目的

把“写完一章”升级为“写完且过节拍门禁”。

## 四拍门禁（单章）

```text
钩子（前200）→ 蓄力（中段加压）→ 回报（中段兑现）→ 留钩（后200）
```

### 通过标准

- 前 200 字：至少 1 个有效钩子（冲突 / 悬念 / 异常 / 动作 / 对话）。
- 中段：至少 1 次可感知回报（关系、处境、信息、行动、身份其一）。
- 后 200 字：存在未闭合压力点，不得用预告腔替代。

### 连续内倾段塌陷检查（新增）

**问题定义**：开篇强钩子之后，连续出现三段或以上的"内部处理"（内心独白/记忆回溯/信息梳理/情绪消化），中间无任何外部打断（对话/动作/环境变化/第三方介入）。读者在掌掴/冲突后被搁置在主角的脑海里，直到章末才回到当下场景。开局的动能被逐步泄空。

**检测方法**：
- [ ] 从章首第一个外部动作之后，是否连续出现≥3个纯内部段落（无对话、无动作、无第三方介入）？
- [ ] 若是，这些纯内部段落的总字数是否≥800字？
- [ ] 内部段之间是否有外部打断（一个新走进来的人、一个突然的声音、一个需要当下回应的压力）？

**典型反面示例**：
```
掌掴（外部冲突）→认出谢氏和明珠（外部→信息）→
原书主线梳理（纯内部）→
十六年毒史回忆（纯内部）→
已知/未知列表（纯内部）→
"我不会替你去死"（内部决心）→
王嬷嬷送灯（外部再次出现）
```
——中间连续三段内部处理，超过1000字无外部事件。读者在第二次内部段已经感受到"怎么还在想"。

**拆洗方案**：
1. **切除**：将最重的信息灌输段（如全书主线介绍）整体删除，移到后续章节自然透露
2. **打断**：在内部段之间插入一个微型外部威胁（脚步声靠近/门缝有影子/远处有人喊她名字）迫使角色中断思考回到当下
3. **压缩+碎片化**：将大段顺滑的回忆拆成2-3个碎片，穿插在不同外部动作之间，读者边看故事边拼凑信息，而不是一次性灌完

## 钩子轮换门禁（跨章）

- 不得连续 3 章使用同类钩子。
- 若连续 2 章同类钩子，第 3 章必须强制换型。

推荐轮换：

```text
悬念钩 → 冲突钩 → 异常钩 → 动作钩 → 对话钩 → 悬念钩...
```

## 日志记录字段（强制）

每章至少记录：

- `HookType`：本章钩子类型
- `MidPayoff`：本章中段回报句（可回指）
- `TailDriver`：章末接棒问题
- `RotationCheck`：是否与前两章过载重复（Yes/No）
- `GatePass`：四拍门禁是否通过（Pass/Fail）

## 失败处置

- `GatePass=Fail`：不得进入终审；必须先回写步骤 2 或专项补丁（开头 / 章末 / 中段回报）。
- `RotationCheck=Yes`：必须在下一章控制卡中预设换型钩子，并标记为高优先级。
