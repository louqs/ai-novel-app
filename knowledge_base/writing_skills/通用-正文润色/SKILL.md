# 通用-正文润色

正文润色的目标不是单纯把句子写漂亮，而是把**已有章节**修到“更顺、更准、更抓人、但不失真”。

当题材 Skill 与本 Skill 组合调用时：

- `通用-正文润色` 负责共性流程、默认交付、弱项路由、句级动作与沉浸控制
- 题材 Skill 负责题材边界、项目特例与裁判源补充

> **规则分层说明**：本 Skill 的规范条款按四层组织（详见 `../规则分类抽样框.md`）：
> **§A 红线** = 违反即错，强制；**§B 工序门禁** = 动手前后的流程纪律；
> **§C 体裁靶值** = 量化阈值，向体裁包取值；**§D 诊断信号** = 体检倾向，非强制门。
> 技法库章节（画面感、快节奏、弱项路由等）是 §D 性质的参考，按需读取，不作硬门。
> 读规则时先认层级：**只有 §A 和 §B 是「必须」，§C 是「向靶值靠拢」，§D 是「优先 / 倾向」。**

---

## §A 红线（违反即错，全体裁通用，强制）

> 只有 5 条。违反任意一条，产出就是**错的**，不是「不够好」。其余看似强制的条款都在 §B/§C/§D。

1. **不新增关键事实、不删减核心信息。** 不得为顺口删掉关键证据、编号、时间点、规则边界。
2. **不得越过润色边界。** 一旦问题涉及增删场景、重排事件、改人物选择、补悬念、补承重 beat 或重设因果，
   必须退回 `writer / 控制卡 / 正文层`，不得用润色硬扛。对话同理：默认只在措辞、标签、声音差与动作配合层动刀，
   不改对话承担的事实内容；若必须改对话内容才成立，说明已超出润色边界。
3. **不得磨平结构功能。** 中段回报、高潮峰值、章末钩子的**存在与清晰度**不可因润色受损。
4. **不得保留章节自指 / 连载导览腔。** 「这几章 / 前几章 / 前面几章 / 前面这几章 / 后几章 /
   后面几章 / 后面这几章 / 整章 / 这整章 / 这一整章 / 上一章 / 下一章 / 本章 / 这章 / 后文会 /
   我们会看到 / 读者会发现」及其全部变体，若原稿已有，必须改写成场景内表达——不是擦亮，是改写。
5. **不得违反裁判源。** 未核对人物传记 / 故事设定前，不得改写人物动机、关系状态、规则表现、
   证据位置或背景事实。（核对动作本身是工序，见 §B-1。）

## §B 工序门禁（动手前 / 回写后的流程纪律，强制，但不参与美学权衡）

> 这些是**流程纪律**：先读什么、加载什么、跑什么脚本。它们强制，但与文笔好坏无关，
> 因此单独成块，不和 §A 红线、§D 信号混读。

### B-1 裁判源复核（动手前）

- 动手润色前，认真仔细阅读与本章实际出场人物对应的人物传记，以及与本章背景、技术、规则、证据、
  程序链、世界观有关的故事设定文档。
- 不得只凭现成正文、上一轮润色痕迹或审阅摘要直接下刀；凡涉及人物动机、能力边界、关系状态、
  设定代价、证据机制的句段，都回到作者侧裁判源核对后再改。
- 若同一人物传记或故事设定存在多个版本，先确认当前可执行的最新版本；若关键裁判源缺失，
  先补齐、定位或明确阻断，不能边猜边润。
- 若本轮润色会触碰人物弧线、规则代价、证据链、关系位置或背景事实，在回写前复核一次相关裁判源，
  确认没有把正文润偏。

### B-2 模板与平台自动发现（动手前；存在即加载，不存在则静默回退）

- 项目根目录存在 `Agents.md` → 读取后按其注册加载：
  - **写作研究模板** → 作为题材×平台的默认约束基线（低于用户明确指定的模板，高于通用默认）。
  - **作者风格模板** → 句长基线、段落节奏、感官偏好、对话标签偏好、比喻指纹、禁忌清单，作为文笔侧裁判源。
  - **作品蓝本模板** → 章首模式指纹、钩子轮换、中段回报间隔、场景节奏、信息释放节拍、情感弧分布，作为结构侧参照。
- `Agents.md` 声明了 `主输出平台` → 按命名约定加载 `通用-输出{平台名}版` Skill，
  其平台门禁（字数门槛、段落节奏偏好、表达风格禁忌）作为本章节润色的约束基线。
- 不存在 `Agents.md` 或未注册对应项 → 回退通用默认模式，不报错、不阻断。

### B-3 字数门禁（回写后）

- 回写前必须重跑字数门禁。**正文字数检测必须使用 `scripts/count-chapter.ps1`**，
  不得用 `Len`、`NoWhitespaceLen`、编辑器字符数或目测代替。
- 用 `scripts/count-chapter.ps1 -Path "CHAPTER_FILE"`；正文门禁只看 `BodyCJK / MeetsMinCJK / WithinRange`，
  `MeetsMinCJK` 必须为 `True`，`WithinRange` 最好为 `True`。
- 含 `## 作者有话说` 时补跑 `scripts/count-afterword.ps1`。
- 记录字数须直接引用脚本字段 `Len / CJK / BodyCJK / MeetsMinCJK / WithinRange / MeetsAll`，
  不得改写成「去空白统计」。
- **字数靶值本身不在此处写死** → 见 §C。

## §C 体裁靶值（量化阈值，向体裁包取值，不在通用规则里写死）

> 以下都是「换个体裁该值就该变」的量化项。通用规则只说「**向本体裁的靶值靠拢；
> 若体裁包未给定，回退括号内通用默认值**」。具体数值由 `genre_skills/{题材}/靶值.md`
> 或 `通用-输出*版` 注入。这样 LLM 不再把唯一硬编码值误当全体裁铁律。

| 参数 | 取值来源（优先级） | 通用回退值 |
|---|---|---|
| 正文字数范围 | ① `Agents.md` 主平台 → ② `通用-输出*版` 平台默认 → ③ 体裁『字数窗口』→ ④ 回退 | 中文正文 2500–5000 CJK |
| 章首抓力判定窗口 | 体裁『章首抓力窗口』 | 前 300 字 / 三句法 / 30 秒 |
| 单处解释长度上限 | 体裁『单处解释长度上限』 | 超过 150 字则拆分 |
| 连续同景别句数上限 | 体裁『镜头节奏靶值』 | 连续 3 句以上需考虑切换 |
| 零画面段落上限 | 体裁『画面密度靶值』 | 连续 300 字 |
| 主视角分配 | 体裁『主视角分配』 | 单一主视角 ≥80% |

> 体裁靶值样板见 `genre_skills/AI科幻/靶值.md`。体裁包只需维护「与通用默认不同」的差量。

## 缓存优化说明

本 Skill 遵循前缀缓存优化原则。润色是高频调用任务，调用时：

- **缓存层（永久不变）**：frontmatter + §A 红线 + §B 工序 + §C 靶值表 + 句级动作库 + 副总裁判标准 + 弱项路由规则
- **项目层（同项目内不变）**：references 清单 + 裁判源复核要求 + 风格/蓝本模板发现规则
- **可变层（每次变化，不写入本文件）**：本次目标章节路径、润色范围、本次特殊约束 → 由用户每次调用时指定

## 共性执行顺序

本 Skill 的各参考文件按以下顺序调度。除非标注"固定先读"，否则按需读取即可。

1. **先读裁判源**（§B-1）：确认不能动的钉子、可增强处与不可越界处。
2. **确认范围与强度**：明确本轮范围（整章/场景/段落）、强度（轻/中/重）与不可改动项。
   → 若对阶段归属有疑问，固定先读 `references/Phase0-3创作修订一体化节拍.md`。
3. **先保信息**（§A-1/§A-3）：确保事实、因果、视角、结构功能不因润色受损。
   → 固定先读 `references/正文润色保真迁移规则.md`；并行读 `references/正文润色数值双轨禁忌与沉浸控制.md`
   （先稳功能线再优化质感线）。
4. **先修追读链**：先修章首抓力，再修中段回报，再修章末钩子。
   → 固定先读 `references/正文润色流程.md`；遇具体执行问题参考 `references/正文润色增强技法与读者机制.md`。
5. **再按弱项路由处理**：对话、动作、心理、肖像、景物、静态或场面。
   → 固定先读 `references/正文润色扩展参考路由.md`，短板明确后按需读对应写作指导文件。
   若遇以下问题，再同步读对应补强文件：
   - 感官描写空泛 → `references/感官链与生理反应补强.md`
   - 抽象信息/术语/数据读感发虚 → `references/抽象梯与事实转译补强.md`
   - 叙事距离控制偏移 → `references/视角与叙述距离修正.md`
   - 段落距感判断不准 → `references/贴脸段中距段过桥段动作卡.md`
   - 需压缩解释而保信息 → `references/删解释保信息的压缩动作卡.md`
   - 功能句需保留功能又写活 → `references/功能句保真改写示例卡.md`
   - **阅读流畅度问题**：当"文字没问题但读着难受"，优先诊断以下三类流畅度事故（均为 §D 信号）：
     - **强迫解释**：标志"原来/其实是/实际上/也就是说"高频 → 删标志词，背景信息压缩自然融入；
       单处解释超过体裁『单处解释长度上限』（§C）则拆分。
     - **分段/标点异常**：①一句一段未讲完→合并到意思完整；②标点密度异常→重组自然语流；
       ③对话与动作分离→同一人对白与动作合并到同段。
     - **视角跳跃**：同段多感知主体 → 固定主视角，删非关键感知，增加过渡信号。
6. **句级精修与链路复检**：
   - 用"润色后链路职责保真复核卡"确认卖点、回报、钩子与场景职责没有被润平（守 §A-3）。
   - 句级精修：`references/正文润色句级动作库.md` 提供通用句级改法。
   - 去 AI 模板腔/斧凿痕 → `references/去斧凿痕与透明叙述校准卡.md`
   - 文字流畅度 → `references/腾讯专栏文字流畅四层次增补.md`；节奏手感 → `references/腾讯专栏行文手感与简洁节奏增补.md`
   - 画面感 → `references/画面感强化技法.md`（参见下方"画面感强化专项"）
   - 沉浸与读者情绪 → `references/正文润色增强技法与读者机制.md` 的"读者机制提醒"与"红线"节
7. **字数门禁**（§B-3）：回写前必须重跑脚本。

## §D 诊断信号（体检倾向，措辞为「优先 / 倾向 / 检查」，非强制门）

> 违反这些，文本只是**更弱**，不是错。它们是审阅视角的体检清单，不是创作时的强制门。
> 刻意用「优先/倾向/检查」而非「必须/不得」，是为了不让 LLM 把它们当可打勾硬指标去塌缩。

### 追读链与开篇

- 前 `300` 字（向体裁『章首抓力窗口』靠拢）**优先**交付人物抓手、第一压力与一个读者会继续看的问题。
- **三句法章首进门检查**：开篇三句是否完成"疑问 + 情绪 + 代入"。若三句全是信息说明，**优先**改造前 1–3 句。
- **切片开头鉴别**：若章首是概括式叙述（大纲体），**优先**改写为切片式——截取最高压/最反常的瞬间作锚点。
  （概括式开头通常需重写而非润色——这是判断**倾向**，不是硬门。）
- 中段润色**倾向**确认本章至少有一次情绪/关系/信息/行动/身份层面的实质回报。

### 句级与情绪

- 精修时**优先**把抽象判断改写成动作、感官、物件、停顿、具体选择与可见后果，减少替角色总结。
- **情绪表达升级**：凡直接写情绪词（愤怒/伤心/恐惧/开心）的句子，**优先**升级到行为/神态/动作层面
  （"他很愤怒"→"他握着手机的手指节发白"）。原则：离底层情绪越远的写法越高级。
  详见 `../通用-执行场景单元/references/知乎精华_文笔四维与交互框架.md` 第三节。
- **环境—角色交互检查**：润色环境段时**检查**角色是否与环境交互；若像两条平行线，**倾向**补一个交互动作。

### 节奏与排版

- 原稿句群同宽、段落过厚时，**倾向**做手机端友好压缩，但不压掉信息与节拍。
- **节奏真伪**：动手前**先区分**真实节奏与假节奏（事件清单）；"读者知道要来了但还没来"的延迟区间
  **倾向只强化不压缩**。（完整五条见下方"润色中节奏真伪判定"节。）

### 人物与边界

- 重要人物的魅力与脆弱**优先**同时可见；**检查**润色是否把真实短板洗成无瑕高光。
- 多问题并存时，**推荐**处理顺序：去 AI 味 → 对话修正 → 描写精炼 → 节奏微调 → 措辞优化。
- 润色后**优先**显式复核情感弧：入口/出口是否仍成立、是否削弱峰值、是否放大谷值；
  若入口≈出口且无合理新设计，**标为**结构性风险并回退上游。
- 本轮结束**默认**产出简短润色回执：处理了哪些问题、情感弧是否保住、哪些已超出润色边界应转 `writer`。

## 弱项路由规则（§D 路由表，非硬规则）

- 对话发直、口气混、说明腔重 → 走"语言类"修法
- 动作发虚、推进靠概括 → 走"行动类"修法
- 心理发空、情绪只会直说 → 走"心理类"修法
- 人物脸模糊、神态无抓手 → 走"肖像类"修法

- 多人现场不热不紧、没有焦点 → 走"场面类"修法

再读 `references/正文润色高级强化技法.md`。

## 画面感强化专项（§D 技法库）

画面感不是"辞藻华丽"，是"读者能在脑子里看到正在发生什么"。完整技法见 `references/画面感强化技法.md`。

### 画面感六步诊断

段落"信息都在但没画面"时，按序快速排查：

1. **有可见物吗？** → 读者脑中能出现至少一个具体物件/身体部位/场景？否则补一个。
2. **动词都准吗？** → 弱动词能否换强动词？是否有情绪标签代替了动作？
3. **空间关系清楚吗？** → 角色在哪儿？东西在哪儿？多远？怎么移动？
4. **光线存在吗？** → 白天还是晚上？亮还是暗？光线对角色造成了什么？
5. **有感官切换吗？** → 是否连续 3 句以上只有视觉？需补听觉/触觉/嗅觉？（句数向体裁『镜头节奏靶值』靠拢）
6. **有可被记住的细节吗？** → 100 字里有一个读者能记住的细节？否则移冗余修饰换有信息量的细节。

### 画面感快速修复口诀

```
信息太多没画面 → 找一个具体物托住
动作太虚没画面 → 把动词换准
环境太空没画面 → 补一个空间坐标 + 光线
心理太深没画面 → 先把心理变成身体反应
情绪太浓没画面 → 用动作代替形容词
对话太干没画面 → 加停顿 + 小动作 + 空间关系
```

### 镜头意识

- **特写**（某物/表情/细节）→ 关键证据、关键情绪、关键转折
- **中景**（动作/互动）→ 推进情节的主力镜头
- **全景**（环境/空间关系）→ 建立场景、交代局势

连续多句用同一种景别时（阈值向体裁『镜头节奏靶值』靠拢），考虑切换镜头距离打破单调。

### 感官定向激活

不是平均分配五感，而是根据场景选择 1-2 种主导感官：

- **恐惧/紧张**：触觉（后颈发凉）+ 听觉（呼吸声/脚步声），忌大量视觉
- **悬疑/不安**：听觉（异响/突然安静）+ 嗅觉（怪异气味）
- **愤怒/冲突**：视觉（红/白）+ 触觉（握拳/发抖）
- **压抑/沉重**：触觉（温度/质感）+ 听觉（低频声）

## 极快节奏与强烈冲突——润色规则（§D 技法库）

### 快节奏润色的核心方向

**1. 句长与段长的多样化** — 避免齐平的单调感：
```
原稿：陈勉走进房间。房间里很暗。他看到了一个人影坐在对面的椅子上。陈勉的心跳加速了。他慢慢走向椅子。那个人影突然站了起来。

润色方向：句长变化 + 短句密集
陈勉推门。房间黑洞洞的。暗处，一个身影站了起来。不对。那不是站，而是突然从黑暗里扑出来。陈勉的脚步一滞。
[短句-短句-中长句-短句的变化制造了加速感]
```

**2. 动词的活跃化与时间信号的即刻化** — 用"即刻发生的动词"代替"正在发生的心理"：
```
❌ 陈勉想起了上次见到这个人的时候。那次他说过如果再见面就不是朋友。陈勉意识到自己可能要面临一些危险。
✅ 陈勉认出了他。"如果再见面就不是朋友。"上次的话浮现在脑子里。危险已经近在咫尺。
```

**3. 转折点与节奏断层的有意设置**：
```
原稿：陈勉走进去，发现房间里有人，他很惊讶，但他想到了应该怎样应对。
润色：
陈勉推门进去。
房间里有人。
那是——不可能。
他应该在医院里。
```

### 强冲突润色的核心方向

**1. 对立的具体化与立场碰撞的即刻化**：
```
❌ 陈勉和对面的人对立了。他们想要的东西不一样。陈勉很害怕，但他不想退缩。
✅ 陈勉盯着对面的人。"把钱放下。"那个人说。"除非你先把人放了，"陈勉说。两个人的目光在半空中撞在一起。无法妥协的两条线。
```

**2. 代价的物化与后果的身体化**：
```
❌ 她意识到自己犯了一个巨大的错误。错误会导致一些可怕的后果。
✅ 她按下的按钮没有回弹。灯灭了。楼下传来了巨大的爆炸声。烟灰透过窗缝吹进来。
```

**3. 权力与位差的动作化表现**：
```
❌ 绑匪掌握了绝对的主动权。他可以决定人质的生死。陈勉感到自己很无力。
✅ 绑匪靠在椅子上，腿搭在桌子上，手里转着一把刀。陈勉站在他五步远的地方，双手垂在身体两侧。"你说。"绑匪说。
```

**4. 信息的非对称性在对话与细节中体现**：
```
陈勉不知道警察已经在楼外围好了。所以他还在和绑匪谈判。而绑匪知道警察在外面，所以他的每一句话都在试探："你告诉我，有多少人在外面？"
[对话中透露：陈勉在猜，绑匪在确认。这就是信息非对称。]
```

### 快节奏 + 强冲突润色检查清单

[ ] 句长是否有明确变化（不是齐平节奏）？
[ ] 段长是否有意识起伏（短段加速，长段沉重）？
[ ] 动词是否都是即时发生的（而非"想象/推测/可能会"）？
[ ] 时间信号是否明确且推进？
[ ] 对立是否具体化（不只是"对立"，而是具体行为、语言、空间对抗）？
[ ] 代价是否身体化（可看、可听、可感的具体后果）？
[ ] 权力分布是否通过动作和姿态体现？
[ ] 信息非对称性是否在对话和细节中有所体现？
[ ] 是否避免了心理总结、作者旁白和抽象描写？
[ ] 整章是否维持"快速+冲突"双重强度，没有某段掉回原节奏？

### 润色中的节奏真伪判定

> **核心原则**：一段文本"读起来快"不等于"节奏好"——它可能只是事件清单式的平推。
> 润色先区分**真实节奏**和**假节奏（事件清单）**，再决定怎么动手。

| 对比项 | 真实节奏 | 假节奏（事件清单） |
| --- | --- | --- |
| 读感 | 读者有"接下来会怎样？"的心理活动 | 读者被动接收信息，没有期待感 |
| 结构 | 存在蓄力-期待-延迟的区间 | 一路平推，A→B→C 线性 |
| 信息释放 | 选择"最吊胃口的时机"释放 | 选择"最方便交代的时机"释放 |
| 文笔特征 | 快时短句密集，慢时长句沉浸 | 句长均匀，无节奏起伏 |
| 概括形式 | "读者在等X→等到X→开始等Y" | "主角做了A→做了B→做了C" |

**保护节奏的五条规则**（均为 §D 倾向）：

- **规则一：不为"顺畅"洗掉预告-兑现结构。** 别把"读者知道要来了但还没来"的延迟区间磨短或删掉。
- **规则二：不用"信息压缩"替代"节奏加速"。** 保持蓄力段文字量，增强每句信息密度与感官唤起，而非删字数。
- **规则三："读者知道要来了但还没来"的区间只能强化不能压缩。** 删词不删意，段长可微调但不整段砍。
- **规则四：区分"推进慢"和"节奏好"。** 推进慢=信息密度低需压缩；节奏好=高密度但刻意延迟揭示，绝不压缩。
- **规则五：润色后复核"爽点预告链是否被洗平"。** 逐一回答：预告定位是否清晰？章首预告信号是否仍在？
  中段蓄力区间是否仍在？章末是否仍制造"下一章有好戏"预期？

> 上述四项中若有两项以上答"被洗平了"，节奏保护未做到位，**建议**回炉（这是质量倾向，非 §A 硬门）。
