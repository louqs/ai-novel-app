# 视角与叙述距离修正

适用于正文已有内容基本成立，但“谁在看、贴多近、作者有没有越位”开始发飘的情况。

## 一、先看这章到底站在谁身上

润色前先判断：

- 当前主视角是谁
- 读者主要跟着谁承担风险
- 这一章的知道 / 不知道，是不是由这个人来制造张力

如果这三项说不清，很多“文笔问题”其实是视角问题。

## 二、常见失真类型

### 1. 作者抢答

- 角色还没判断出来
- 叙述已经把真相、动机、后果说透

修法：

- 把结论拆回角色看到 / 听到 / 猜到的东西
- 必要时保留误判，不急着修正

### 2. 贴脸突然飞走

- 前面明明在角色耳边、眼前、胃里
- 后面突然用总结腔概括整段局势

修法：

- 先保留贴脸段的感官和动作
- 把总述压成 1 句过桥，再尽快落回现场

### 3. 限知漏成上帝视角

- 有限视角章节里，突然写出别人的内心、远处发生的事、角色不可能知道的背景

修法：

- 改成推测、误读、迹象
- 或改成后续通过对话 / 界面 / 证据得知

## 三、润色时如何判断“贴得够不够近”

检查当前段落是否至少命中两项：

- 角色眼前的具体物
- 角色当下身体反应
- 角色即时判断 / 误判
- 角色马上要做的动作

若四项全无，只剩总结，多半贴得不够近。

## 四、何时允许保持中距或远距

不是所有段落都必须贴脸。

可保留中距 / 远距的场景：

- 过程压缩
- 时间跳转
- 阶段性整理
- 章节过桥

但要警惕：

- 远距段落一长，人物就容易失温
- 一失温，读者就从戏里掉出去

## 五、第一人称特有风险

- 太爱声音，结果满页都在“我来解释”
- 太爱聪明，结果叙述者什么都懂
- 太爱表演，结果人物不像人，像段子机

修法：

- 保留声音，但删掉多余聪明
- 留出人物嘴硬、短视、偏见和局限
- 让“我”也会误会、停顿、说岔、硬撑

## 六、第三人称限知特有风险

- 看似稳，实则到处偷心读术
- 句子太平，像无人机在拍

修法：

- 把叙述重新染上该人物的偏好、厌恶、注意力分布
- 就算不用“我”，也要让人感觉这是“他会这样看”

## 七、实用替换法

### 把作者总结改成角色可感

- 弱：她已经知道自己被针对了。
- 强：她把话听完，手却没从门把上松开。那点客气，已经薄得像纸。

### 把全知判断改成有限视角迹象

- 弱：走廊尽头那个人此刻正在犹豫是否报警。
- 强：走廊尽头那人摸出手机，又塞了回去，站在原地没动。

## 八、最终验收

- 这一章的镜头是不是基本跟着同一个意识在走？
- 角色不知道的内容，是否被改成了可见迹象或后续得知？
- 是否把“更好懂”误做成了“全说透”？
- 润完后，读者是不是更贴人物，而不是更贴作者？
## 九、视角塌陷专项诊断（新增）

视角塌了 = 作者站在故事外面，像纪录片摄影师把主角从头到脚拍了一遍，而不是让读者透过主角的眼睛和身体去感受。

### 典型病灶

**原文（作者在外部拍摄）**：
> 穆尘的腿不争气地颤抖。他并不知道这是哪里，但并不感到陌生，潜意识告诉他，你曾来过这。

**问题**：每一句都是作者在替主角做全知总结——"腿在颤抖"（外部拍摄）、"并不知道这是哪里"（替主角总结）、"潜意识告诉他"（替主角解释心理机制）。

**改后（视角贴在主角身上）**：
> 穆尘低头看了一眼自己的腿。在抖。停不下来。这里……来过？不可能。他咽了口唾沫，嗓子干得像吞了把沙子。

### 快速诊断口诀

当前段落是否至少命中两项？
- 角色眼前的具体物
- 角色当下身体反应
- 角色即时判断 / 误判
- 角色马上要做的动作

若四项全无，只剩总结，多半是视角塌了。

### 摄像头视角实操

- 摄像头架在主角肩上 → 读者只能看到主角看到的、听到主角听到的
- 主角没看到的东西，读者就不能知道
- 主角不知道自己在哪，读者就不能提前知道
- 用受限视角写一章，会立刻暴露此前在用上帝视角剧透弥补叙事不足

## 十、五感替换法（新增）

搜索以下五个词，全部删掉，换成具体感官描写：**很、非常、特别、极其、无比**。

| 抽象概括 | 感官替换 |
| --- | --- |
| 他很紧张 | 手心出汗、喉结滚动、目光往门口飘 |
| 她很害怕 | 往后退了半步，脚后跟抵到了墙根 |
| 这个东西很臭 | 鼻腔里灌进一股沤了三天的泔水味 |
| 他很累 | 腿早就不是自己的了，肺里塞了一团烧红的棉花 |
| 非常痛 | 疼得视野发白，耳朵里嗡嗡响 |

练到能条件反射地把概括词换成画面，描写自然就不尬了。
